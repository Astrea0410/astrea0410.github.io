입력값이 바뀔 때마다 미리보기를 업데이트합니다.

EVT-11

키보드 입력 확인하기

입력 필드에서 눌린 키의 이름을 확인합니다.

EVT-12

EVT-13

EVT-14

선택 메뉴에 반응하기

EVT-15
