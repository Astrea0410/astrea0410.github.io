01 element { } Element Selector

요소(태그) 선택자

HTML 태그 이름으로 요소를 직접 선택합니다. 페이지 내 해당 태그가 붙은 모든 요소에 스타일이 적용됩니다. 전역 기본 스타일을 설정할 때 주로 사용합니다.

p { color: teal; }
p {
  background: #d0e8e8;
  border-left: 3px solid teal;
  padding: .5rem .9rem;
  color: #1a6b6b;
}

/* 모든 <p> 태그에 적용 */

02 .class { } Class Selector

클래스 선택자

HTML 요소의 class 속성 값으로 선택합니다. 점(.)으로 시작하며, 여러 요소에 같은 클래스를 붙여 재사용할 수 있습니다. 가장 실용적인 선택자입니다.

.tag-html { background: #ffe0cc; }
.tag-html {
  background: #ffe0cc;
  color: #c04400;
}
.tag-css {
  background: #cce5ff;
  color: #0055aa;
}
/* class="tag-html" 요소에 적용 */

03 #id { } ID Selector

ID 선택자

HTML 요소의 id 속성 값으로 선택합니다. 샵(#)으로 시작하며, ID는 페이지 내 단 하나의 요소에만 사용해야 합니다. 특정 단일 요소에 고유 스타일을 줄 때 사용합니다.

#demo3-hero { background: #1a1714; }
#demo3-hero {
  background: #1a1714;
  color: #f5f0e8;
  padding: 1.2rem 1.5rem;
  border-radius: 4px;
}
/* id="demo3-hero" 단 하나에 적용 */

04 ancestor descendant { } Descendant Selector

자손(하위) 선택자

특정 요소의 내부에 있는 모든 하위 요소를 선택합니다. 공백( )으로 구분하며, 직접 자식뿐 아니라 깊이에 관계없이 모든 자손에게 적용됩니다.

.ancestor span { color: gold; }
.ancestor span {
  background: #f5ecc8;
  color: #b8860b;
  padding: .25rem .75rem;
  border-radius: 3px;
}
/* .ancestor 안 모든 span에 적용 */

05 selector:pseudo-class { } Pseudo-class Selector

가상 클래스 선택자

요소의 특정 상태나 위치에 따라 스타일을 적용합니다. 콜론(:)으로 구분하며 :hover, :first-child, :nth-child() 등이 있습니다.

li:first-child { background: pink; }
li:nth-child(even) { background: #eee; }
li:first-child {
  background: #f0d5c8;
  color: #c0440a;
}
li:nth-child(even) {
  background: #ede8dc;
}
li:hover {
  background: #d0e8e8;
}

06 [attribute="value"] { } Attribute Selector

속성 선택자

요소의 HTML 속성과 값으로 선택합니다. 대괄호([ ])로 표현하며, [type="email"]처럼 속성 값에 따라 각기 다른 스타일을 줄 수 있어 폼(form) 디자인에 특히 유용합니다.

input[type="email"] { border: teal; }
input[type="password"] { border: rust; }
input[type="text"] {
  border-color: gold;
}
input[type="email"] {
  border-color: teal;
}
input[type="password"] {
  border-color: rust;
}
