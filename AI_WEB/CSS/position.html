static

기본값 — 문서 흐름 그대로

모든 요소의 기본값입니다. top / left / z-index가 무시되며, 작성된 순서대로 위에서 아래로 배치됩니다.

▶ 프리뷰
Box 1 — static
Box 2 — static
Box 3 — static
.box {
  position: static; /* 기본값, 생략 가능 */
  top: 20px;       /* ← 무시됨 */
}
relative

원래 위치 기준으로 이동

원래 있던 자리를 기준으로 top / left / right / bottom 만큼 이동합니다. 원래 자리는 그대로 예약되어 다른 요소에 영향을 주지 않습니다.

▶ 프리뷰 — Box B가 top:14px, left:20px 이동
Box A
Box B 원래 위치
Box C
Box B (이동됨)
.box-b {
  position: relative;
  top:  14px;  /* 원래 위치에서 아래로 14px */
  left: 20px;  /* 원래 위치에서 오른쪽으로 20px */
}
absolute

가장 가까운 positioned 부모 기준

문서 흐름에서 완전히 이탈하여 떠오릅니다. 기준점은 position: relative/absolute/fixed가 설정된 가장 가까운 조상 요소입니다. 없으면 <html>이 기준.

▶ 프리뷰 — 부모(relative) 기준으로 각 모서리에 배치
부모 — position: relative
top:32 left:10
top:32 right:10
bottom:10 left:10
bottom:10 right:10
.parent {
  position: relative; /* 기준 컨테이너 */
}

.child {
  position: absolute;
  top:    32px;
  right:  10px;
}
fixed

뷰포트(화면) 기준으로 고정

스크롤해도 화면에 고정됩니다. 기준은 브라우저 뷰포트이며 문서 흐름에서 이탈합니다. 헤더 네비, 채팅 버튼, 쿠키 배너 등에 사용합니다.

▶ 프리뷰 — 이 페이지 우측 하단의 빨간 배지가 fixed 예제입니다
📌 position: fixed

스크롤을 내려도 우측 하단 배지는
항상 같은 자리에 있습니다.

.fixed-badge {
  position: fixed;
  bottom: 24px;
  right:  24px;
  z-index: 1000; /* 다른 요소 위에 표시 */
}
sticky

스크롤 임계점까지 relative, 이후 fixed

평소에는 relative처럼 흐름을 유지하다가, 스크롤이 top 값에 도달하면 그 자리에 고정됩니다. 테이블 헤더, 섹션 타이틀 고정에 유용합니다.

z-index — 쌓임 순서

position이 static이 아닌 요소에만 작동합니다. 값이 클수록 앞에(위에) 표시됩니다.

▶ 프리뷰
z-index:1
z-index:2
z-index:3
.box-blue   { position: absolute; z-index: 1; }
.box-orange { position: absolute; z-index: 2; }
.box-red    { position: absolute; z-index: 3; } /* 맨 위 */
