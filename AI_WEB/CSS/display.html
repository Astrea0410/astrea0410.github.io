Block 요소 vs Inline 요소

HTML 요소가 화면에 배치되는 방식을 결정하는 display 속성의 완전 가이드

개요

Display 속성 비교

⬛ block

  • 새 줄에서 시작
  • 가로폭 100% 차지
  • width / height 적용
  • margin / padding 모두 적용
  • 옆에 나란히 배치 불가

▬ inline

  • 새 줄 시작 안 함
  • 콘텐츠 크기만큼만 차지
  • width / height 무시됨
  • 좌우 margin/padding만 완전 적용
  • 텍스트 흐름 안에 배치

⊡ inline-block

  • 새 줄 시작 안 함
  • width / height 적용
  • margin / padding 모두 적용
  • 옆에 나란히 배치 가능
  • block + inline의 혼합

BLOCK

Block 요소 예제

<div> — 범용 블록 컨테이너

의미 없는 레이아웃 묶음. 항상 새 줄에서 시작하고 가로폭 전체를 차지합니다.

<div style="background:#1e3a5f; padding:16px; border-radius:8px;">
  첫 번째 div
</div>
<div style="background:#3a1e5f; padding:16px; border-radius:8px;">
  두 번째 div — 자동으로 다음 줄에 배치
</div>
▶ 라이브 프리뷰
첫 번째 div
두 번째 div — 자동으로 다음 줄에 배치됨

<h1> ~ <h6> — 제목 태그

문서의 계층적 제목을 나타냅니다. 모두 block 요소로, 각자 새 줄을 차지합니다.

<h1>H1 — 최상위 제목</h1>
<h2>H2 — 하위 제목</h2>
<h3>H3 — 소제목</h3>
▶ 라이브 프리뷰
H1 — 최상위 제목
H2 — 하위 제목
H3 — 소제목

<p> — 단락

텍스트 단락을 묶는 가장 기본적인 블록 요소. 위아래 여백이 자동으로 추가됩니다.

<p>첫 번째 단락입니다. Block이므로 독립적인 줄을 가집니다.</p>
<p>두 번째 단락. 자동으로 아래 줄에 위치합니다.</p>
▶ 라이브 프리뷰
첫 번째 단락입니다. Block이므로 독립적인 줄을 가집니다.
두 번째 단락. 자동으로 아래 줄에 위치합니다.

<ul> / <ol> / <li> — 목록

순서 없는 목록(ul)과 순서 있는 목록(ol). <li> 항목 자체도 block 요소입니다.

<ul>
  <li>HTML 기초</li>
  <li>CSS 레이아웃</li>
  <li>JavaScript</li>
</ul>
▶ 라이브 프리뷰
  • HTML 기초
  • CSS 레이아웃
  • JavaScript

<table> — 표

2차원 데이터를 행과 열로 표현합니다. 기본값은 display: table이지만 블록처럼 동작합니다.

<table>
  <tr><th>이름</th><th>타입</th></tr>
  <tr><td>div</td><td>block</td></tr>
</table>
▶ 라이브 프리뷰
태그기본 display설명
divblock범용 컨테이너
pblock단락
sectionblock의미적 섹션

<section> <article> <header> <footer> <main> <nav> — 시맨틱 태그

HTML5의 의미론적 블록 요소들. div처럼 동작하지만 콘텐츠의 역할을 명시합니다.

▶ 라이브 프리뷰
<header>
사이트 헤더 영역
<main> → <article>
본문 콘텐츠 영역
<footer>
사이트 푸터 영역

INLINE

Inline 요소 예제

<span> — 범용 인라인 컨테이너

텍스트 일부에 스타일을 적용할 때 사용. 자체 의미는 없으며 텍스트 흐름을 유지합니다.

<p>
  가격: <span style="color:orange; font-weight:bold;">29,000원</span>
  (부가세 포함)
</p>
▶ 라이브 프리뷰
가격: 29,000원 (부가세 포함) — span은 텍스트 흐름 안에 배치됩니다.

<a> — 하이퍼링크

다른 페이지나 앵커로 이동하는 링크. inline이므로 문장 중간에 삽입 가능합니다.

<p>
  자세한 내용은
  <a href="#">공식 문서</a>를 참고하세요.
</p>
▶ 라이브 프리뷰
자세한 내용은 공식 문서를 참고하세요. 링크는 텍스트 흐름을 끊지 않습니다.

<strong> <em> <code> <mark> — 텍스트 강조

모두 inline 요소입니다. 텍스트의 의미를 다르게 표현하지만 줄바꿈을 일으키지 않습니다.

<p>
  <strong>중요 내용</strong>은 볼드로,
  <em>강조 내용</em>은 이탤릭으로,
  <code>display:block</code>은 코드 스타일로,
  <mark>하이라이트</mark>는 형광펜 효과.
</p>
▶ 라이브 프리뷰
중요 내용은 볼드로, 강조 내용은 이탤릭으로, display:block은 코드 스타일로, 하이라이트는 형광펜 효과. 모두 같은 줄에 배치됩니다.

<img> <input> <button> — 대체 인라인 요소

기본은 inline이지만 width/height가 적용되는 replaced element입니다. 실제로는 inline-block처럼 동작합니다.

<p>
  검색어:
  <input type="text" placeholder="입력...">
  <button>검색</button>
</p>
▶ 라이브 프리뷰
검색어: — 텍스트와 같은 줄에 나란히 위치합니다.

<sub> <sup> <abbr> — 기타 인라인 요소

위첨자, 아래첨자, 약어를 표현합니다. 모두 텍스트 흐름 안에 삽입됩니다.

<p>
  H<sub>2</sub>O 는 물이고,
  E=mc<sup>2</sup>는 아인슈타인 공식.
  <abbr title="HyperText Markup Language">HTML</abbr> 참조.
</p>
▶ 라이브 프리뷰
H2O 는 물이고, E=mc2는 아인슈타인 공식. HTML은 마크업 언어입니다.

INLINE-BLOCK

display: inline-block

Block + Inline의 장점을 합친 혼합형

같은 줄에 나란히 배치되면서(inline), width/height/margin/padding을 모두 제어할 수 있습니다(block).

<div style="display:inline-block; width:120px; height:60px;
         background:#4f8ef7; margin:8px; padding:10px;">
  박스 1
</div>
<div style="display:inline-block; width:180px; height:90px;
         background:#b47cf7; margin:8px; padding:10px;">
  박스 2 (더 크게)
</div>
▶ 라이브 프리뷰 — 크기가 달라도 같은 줄에 배치
박스 1
120×60
박스 2
180×90
박스 3 (넓게)
240×48
박스 4
NONE

display: none

요소를 완전히 숨김 — 공간도 차지하지 않음

visibility: hidden이 공간은 유지한 채 숨기는 것과 달리, display: none은 레이아웃에서 완전히 제거됩니다.

<div>이 요소는 보입니다.</div>

<div style="display: none;">
  이 요소는 숨겨져 있습니다. /* 공간도 없음 */
</div>

<div>이 요소는 보입니다 — 위 요소 없이 바로 이어집니다.</div>
▶ 라이브 프리뷰
① 이 요소는 보입니다.
② 이 요소는 display:none — 존재하지 않음
③ 이 요소는 보입니다 — ②가 없으므로 ①바로 다음에 이어집니다.
⚠ ② 요소는 HTML에 있지만 display:none으로 화면과 레이아웃에서 완전히 제거됨
CSS

CSS로 display 속성 변경하기

기본값을 CSS로 재정의할 수 있습니다

HTML 태그의 기본 display 값은 CSS로 언제든지 바꿀 수 있습니다.

/* 기본이 block인 div를 inline으로 변경 */
div {
  display: inline;
}

/* 기본이 inline인 span을 block으로 변경 */
span {
  display: block;
}

/* a 태그를 버튼처럼 inline-block으로 */
a.btn {
  display: inline-block;
  padding: 10px 24px;
  width: 160px;
}

/* Flexbox / Grid — 현대 레이아웃 */
.container {
  display: flex;   /* 또는 grid */
}
▶ <a>를 inline-block 버튼으로 변환한 예
