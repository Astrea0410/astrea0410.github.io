SECTION 01 font 속성
font-family 01
Typography defines character.
font-family: 'Georgia', serif;
font-family는 텍스트의 글꼴을 지정합니다. 쉼표로 대체 폰트를 나열하며 마지막은 serif·sans-serif 등 일반 계열로 마무리합니다.
font-size / font-weight 02
크고 굵게 700 작고 얇게 300
font-size: 1.6rem; font-weight: 700; /* 100–900 */
font-size는 글자 크기(px·rem·em·%), font-weight는 굵기(100~900)를 설정합니다. rem은 루트 기준 상대 단위입니다.
font-style / font-variant 03
Italic — 기울임 텍스트 small-caps variant
font-style: italic; font-variant: small-caps;
font-style은 normal·italic·oblique를 설정합니다. font-variant: small-caps는 소문자를 작은 대문자로 표시합니다.
font 단축속성 04
font 단축으로 한 번에 설정
font: italic 700 1.2rem/1.9 'Georgia', serif; /* style weight size/line-height family */
font 단축속성은 style·variant·weight·size/line-height·family를 한 줄에 표기합니다. size와 family는 필수입니다.

color — 16진수 사용법 05
#e8c87a 골드 #7ab8e8 블루 #e87ab0 핑크 #98d4a0 민트
color: #e8c87a; /* R=e8 G=c8 B=7a (각 16진수 2자리) */ color: #fff; /* 3자리 축약형: #ffffff와 동일 */ background-color: #0d0f14;
16진수 색상은 #RRGGBB 형식으로 각 채널을 00~ff(0~255)로 표현합니다. #fff처럼 3자리 축약도 가능합니다. 불투명도를 추가하면 #RRGGBBAA 8자리가 됩니다.

SECTION 03 text 속성
text-align / line-height 06

left 정렬 · line-height 1.3

center 정렬 · line-height 1.8

right 정렬 · line-height 2.2

text-align: center; /* left|right|justify */ line-height: 1.8; /* 배수·px·% */
text-align은 텍스트 수평 정렬, line-height는 행간을 설정합니다. 가독성에는 1.5~1.8이 권장됩니다.
letter/word-spacing 07
letter spacing .25em 단어 사이 word spacing
letter-spacing: .25em; /* 자간 */ word-spacing: 1.2rem; /* 단어 간격 */
letter-spacing은 글자 사이 간격(자간), word-spacing은 단어 간격을 조절합니다. em 단위는 현재 font-size에 비례합니다.
text-indent / white-space 08

　들여쓰기 2em — 단락의 첫 줄이 두 글자만큼 안으로 들어갑니다.

nowrap + ellipsis: 긴 텍스트가 넘치면 생략 부호로 잘립니다.

text-indent: 2em; white-space: nowrap; text-overflow: ellipsis;
text-indent는 첫 줄 들여쓰기, white-space: nowrap은 줄바꿈 방지, text-overflow: ellipsis는 넘침 텍스트를 '…'으로 처리합니다.
text-shadow 09
기본 그림자 글로우 효과 아웃라인 효과 레이어 그림자
/* x y blur color */ text-shadow: 2px 2px 4px #000000; /* 글로우: blur만 크게, 색=텍스트색 */ text-shadow: 0 0 12px #e8c87a, 0 0 30px #c0940050; /* 아웃라인: 4방향 그림자 합산 */ text-shadow: 1px 1px 0 #7ab8e8, -1px -1px 0 #7ab8e8;
text-shadow는 x-offset y-offset blur-radius color 순서입니다. 쉼표로 여러 그림자를 중첩해 글로우·아웃라인·레이어 효과를 만들 수 있습니다.

SECTION 04 direction · decoration · transform
direction / unicode-bidi 10

direction: ltr (기본)

왼쪽 → 오른쪽 읽기 방향

direction: rtl (아랍어 등)

오른쪽 ← 왼쪽 읽기 방향

unicode-bidi: bidi-override — 글자 순서 강제 반전

direction: ltr; /* left-to-right (기본) */ direction: rtl; /* right-to-left (아랍·히브리어) */ unicode-bidi: bidi-override; /* 방향 강제 적용 */
direction은 텍스트 쓰기 방향을 지정합니다. ltr(기본)은 왼→오, rtl은 오→왼 방향으로 아랍어·히브리어 등 다국어 레이아웃에 사용합니다. unicode-bidi와 함께 쓰면 방향을 강제할 수 있습니다.
text-decoration —
underline solid — 골드 underline wavy — 블루 overline dashed — 핑크 line-through 3px — 오렌지 none — 장식 없음 (링크 초기화)
text-decoration: underline; text-decoration-color: #e8c87a; text-decoration-style: wavy; /* solid|dashed|dotted|wavy|double */ text-decoration-thickness: 3px; /* 단축형: */ text-decoration: underline wavy #7ab8e8 2px;
text-decoration은 밑줄·윗줄·취소선을 설정합니다. -color로 색, -style로 선 스타일, -thickness로 두께를 세부 제어할 수 있습니다. 단축속성으로 한 번에 작성도 가능합니다.
text-transform —
uppercase — 모두 대문자 LOWERCASE — 모두 소문자 capitalize — 첫글자 대문자 none — 원본 그대로 유지
text-transform: uppercase; /* 모두 대문자로 변환 */ text-transform: lowercase; /* 모두 소문자로 변환 */ text-transform: capitalize; /* 각 단어 첫 글자 대문자 */ text-transform: none; /* 변환 없음 (기본값) */
text-transform은 HTML 원본을 바꾸지 않고 CSS로만 대소문자를 변환합니다. uppercase는 브랜드명·버튼·레이블에, capitalize는 제목에 자주 사용합니다.
