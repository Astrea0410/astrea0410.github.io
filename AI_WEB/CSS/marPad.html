Margin — 바깥 여백

기본 문법

.box {
  margin-top:    20px;  /* 위 */
  margin-right:  16px;  /* 오른쪽 */
  margin-bottom: 20px;  /* 아래 */
  margin-left:   16px;  /* 왼쪽 */

  /* 단축 속성 */
  margin: 20px;             /* 상하좌우 동일 */
  margin: 20px 16px;       /* 상하 | 좌우 */
  margin: 10px 16px 20px;  /* 상 | 좌우 | 하 */
  margin: 10px 8px 20px 16px; /* 상 우 하 좌 (시계방향) */
}

margin 예제 — 요소 사이 간격 만들기

margin-bottom: 8px
margin-bottom: 24px
기준 박스
.box1 { margin-bottom: 8px; }
.box2 { margin-bottom: 24px; }

margin: auto — 가운데 정렬

좌우 margin을 auto로 설정하면 block 요소가 수평 가운데 정렬됩니다.

margin: 0 auto
.center {
  width: 60%;
  margin: 0 auto; /* 상하 0, 좌우 자동 */
}

⚠ margin 겹침 (Collapsing)

상하 인접 요소의 margin은 더해지지 않고 큰 쪽 하나만 적용됩니다. 좌우는 겹치지 않습니다.

margin-bottom: 30px
margin-top: 20px
실제 간격
30px
(30+20 아님)
Padding — 안쪽 여백

기본 문법

.box {
  padding-top:    20px;  /* 위 */
  padding-right:  16px;  /* 오른쪽 */
  padding-bottom: 20px;  /* 아래 */
  padding-left:   16px;  /* 왼쪽 */

  /* 단축 속성 — margin과 동일한 규칙 */
  padding: 20px;
  padding: 12px 24px;        /* 상하 | 좌우 */
  padding: 8px 16px 12px 16px; /* 상 우 하 좌 */
}

padding 예제 — 내용과 테두리 사이 공간

padding: 4px 8px
텍스트
padding: 12px 24px
텍스트
padding: 24px 40px
텍스트
.btn-sm { padding: 4px 8px; }
.btn-md { padding: 12px 24px; }
.btn-lg { padding: 24px 40px; }

padding과 box-sizing

box-sizing: content-box(기본)는 padding이 width에 더해지지만, border-box는 padding을 width 안에 포함합니다.

content-box (기본)
실제 너비:
150 + 32 = 182px
border-box (권장)
실제 너비:
그대로 150px 
/* 모든 요소에 border-box 적용 (권장) */
*, *::before, *::after {
  box-sizing: border-box;
}
