Chapter One

경계선 — border 속성 종류

border-style: solid 실선
solid 실선
border: 3px solid #1755a8;
solid는 끊김 없는 실선입니다. 가장 많이 쓰이는 기본 스타일로 버튼·카드·입력창 등에 활용됩니다.
border-style: dashed 파선
dashed 파선
border: 3px dashed #c07a00;
dashed는 짧은 막대가 반복되는 파선입니다. 드래그앤드롭 영역·점선 구분선·임시 상태 표시에 사용합니다.
border-style: dotted 점선
dotted 점선
border: 3px dotted #6b35b8;
dotted는 작은 점이 연속된 점선입니다. 섬세한 구분선이나 장식적 효과에 어울립니다.
border-style: double 이중선
double 이중선
border: 6px double #0e7a52; /* 최소 3px 이상이어야 보임 */
double은 두 개의 실선 사이에 공백이 있는 이중선입니다. 두께가 최소 3px 이상이어야 눈에 보입니다.
border-style: groove / ridge 입체
groove — 홈 파인 느낌
ridge — 돌출된 느낌
border: 4px groove #c0380a; border: 4px ridge #c0380a;
groove은 안으로 파인 3D 효과, ridge는 바깥으로 돌출된 3D 효과입니다. 밝고 어두운 그림자로 입체감을 표현합니다.
border-style: inset / outset 입체2
inset — 눌린 느낌
outset — 튀어나온 느낌
border: 4px inset #888; border: 4px outset #888;
inset은 전체 박스가 눌린 느낌, outset은 돌출된 느낌을 줍니다. groove/ridge보다 더 단순한 3D 표현입니다.
border 방향별 개별 지정 방향
border-top only
border-left only
bottom + right
border-top: 4px solid #c0380a; border-right: 4px solid #color; border-bottom: 4px dashed #color; border-left: 4px solid #color;
상·우·하·좌 각각 두께·스타일·색상을 독립적으로 지정할 수 있습니다. 단축형으로 border: top right bottom left 4값 순서로도 작성합니다.
border-radius — 모서리 둥글기 radius
4px
12px
50%
50% 0
border-radius: 12px; border-radius: 50%; /* 원형 */ /* 각 모서리 개별: 좌상 우상 우하 좌하 */ border-radius: 8px 0 8px 0;
border-radius는 모서리 곡률을 설정합니다. 4값으로 각 꼭짓점을 개별 지정하고, 50%이면 완전한 원이 됩니다.

margin · padding — 여백 속성

박스 모델 구조 — Box Model Diagram

MARGIN (바깥 여백)

BORDER (경계선)

PADDING (안쪽 여백)

CONTENT (콘텐츠 영역)
Margin — 요소 바깥 여백, 배경색 없음
Border — 경계선, 두께·색·스타일 지정
Padding — 콘텐츠와 경계선 사이 안쪽 여백
Content — 실제 텍스트·이미지 영역
margin — 바깥 여백 MARGIN
요소 A
요소 B — margin-top:1.2rem
margin: 20px; /* 4방향 동일 */ margin: 10px 20px; /* 상하 / 좌우 */ margin: 10px 20px 15px; /* 상/좌우/하 */ margin: 5px 10px 15px 20px; /* 상 우 하 좌 */ margin-top: 1.2rem; margin: 0 auto; /* 수평 가운데 정렬 */
margin은 요소 바깥의 여백입니다. 인접한 두 요소의 margin은 겹침(Collapsing)이 발생해 큰 값 하나만 적용됩니다.
margin: 0 auto는 블록 요소를 수평 가운데 정렬할 때 사용합니다.
음수 값도 허용되어 요소를 겹치게 할 수 있습니다.
padding — 안쪽 여백 PADDING
padding: .7rem 1.4rem .7rem .7rem
padding: 1.4rem (4방향 균등)
padding: 20px; /* 4방향 동일 */ padding: 10px 24px; /* 상하 / 좌우 */ padding: 8px 16px 12px 16px; /* 상 우 하 좌 */ padding-top: 2rem; padding-left: 1.5rem; /* box-sizing에 따라 크기 포함 여부 다름 */ box-sizing: border-box;
padding은 콘텐츠와 border 사이의 안쪽 여백입니다. 배경색·이미지가 padding 영역까지 채워집니다.
box-sizing: border-box를 쓰면 padding이 width/height 안에 포함되어 크기 계산이 직관적입니다.
음수 값은 허용되지 않습니다.
구분 margin (바깥 여백) padding (안쪽 여백) 비고
위치 border 바깥쪽 border와 content 사이 박스 모델 기준
배경색 적용 안 됨 (투명) 배경색/이미지 채워짐 시각적 차이 핵심
음수 값 허용 (요소 겹침) 불가
auto 값 수평 가운데 정렬 사용 불가 margin: 0 auto
겹침 인접 margin 겹침 발생 겹침 없음 Margin Collapsing

Chapter Three

box-shadow — 박스 그림자

문법 (Syntax)

box-shadow: offset-x offset-y blur-radius spread-radius color inset;

→ x이동 y이동 번짐(blur) 크기확대(spread) 색상 [안쪽 그림자 여부]

기본 그림자 basic
기본 그림자
box-shadow: 4px 4px 8px rgba(0,0,0,0.2);
x=4px 우측, y=4px 아래로 이동한 기본 그림자입니다. blur 8px로 자연스럽게 퍼집니다.
spread 확대 그림자 spread
링 효과
box-shadow: 0 0 0 4px #1755a8; /* offset없이 spread만 → 테두리링 */
x·y·blur을 0으로 두고 spread만 주면 border처럼 사용할 수 있습니다. outline과 유사하지만 레이아웃에 영향을 주지 않습니다.
inset — 안쪽 그림자 inset
눌린 느낌
box-shadow: inset 3px 3px 8px rgba(0,0,0,0.25);
inset 키워드를 앞에 추가하면 그림자가 요소 안쪽으로 들어갑니다. 눌린 버튼·오목한 입력창 효과에 사용합니다.
컬러 글로우 효과 glow
Glow
box-shadow: 0 0 16px 4px rgba(107,53,184,0.6);
x·y=0, blur을 크게, spread를 약간 주면 네온 글로우 효과가 됩니다. 다크 배경에서 특히 효과적입니다.
다중 그림자 (레이어) multi
자연스러운 깊이
box-shadow: 0 1px 2px rgba(0,0,0,.06), 0 4px 8px rgba(0,0,0,.08), 0 12px 24px rgba(0,0,0,.08);
쉼표로 여러 그림자를 레이어처럼 쌓습니다. 작은 blur부터 큰 blur까지 단계적으로 주면 현실적인 깊이감이 생깁니다.
뉴모피즘 (Neumorphism) neum
뉴모피즘
box-shadow: 6px 6px 12px #b8b5ae, -6px -6px 12px #ffffff; /* 어두운 그림자 + 밝은 그림자 */
뉴모피즘은 밝은 그림자와 어두운 그림자를 반대 방향으로 조합해 표면에서 솟아오른 부드러운 입체감을 표현합니다.
