게임 개발자 취업 로드맵

AI소프트웨어과에서 배운 프로그래밍 기초를 실제 게임 제작 능력으로 연결하고, 프로젝트와 포트폴리오를 통해 게임 개발 직무 취업을 준비하는 15단계 가이드입니다.

15단계 로드맵1년 학습 계획기술 스택포트폴리오진행 체크

목표와 학습 방향

학습한 기술을 실제로 작동하는 게임으로 연결하는 것이 핵심입니다.

🎯 최종 목표

게임 개발 직무에 필요한 프로그래밍 역량, 제작 경험, 협업 경험, 포트폴리오를 확보합니다.

🧭 우선 경로

Unity와 C#을 중심으로 게임 클라이언트 개발을 먼저 학습합니다. 한 엔진을 충분히 익힌 뒤 다른 엔진으로 확장합니다.

🧪 학습 원칙

개념을 배운 날 작은 기능을 직접 구현하고, 매달 실행 가능한 결과물을 완성합니다.

추천 시작점: Unity 6.3 LTS 환경을 사용하고 있다면 Unity + C#으로 학습 경로를 통일하세요. 여러 엔진을 동시에 시작하기보다 하나의 엔진으로 완성 경험을 쌓는 편이 효율적입니다.

게임 개발자 취업을 위한 15단계

각 단계마다 개념 학습과 실습 결과물을 함께 남기세요.

01

직무 이해 및 선택

게임 개발의 세부 직무를 비교하고 목표 역할을 정합니다.

클라이언트서버게임플레이
  • 클라이언트: 조작, 전투, UI 구현
  • 서버: 로그인, 매칭, 데이터, 네트워크
  • 게임플레이: 규칙, 스킬, 상호작용
실습: 관심 기업 채용 공고 5개를 읽고 공통 요구 기술을 정리합니다.
02

프로그래밍 기초

게임 로직의 기본이 되는 C# 문법을 익힙니다.

C#조건문반복문함수
  • 자료형, 연산자, if/switch, for/while
  • 메서드, 배열, 리스트, 예외 처리
  • 클래스, 객체, 상속, 인터페이스
실습: 숫자 맞히기, 전투 계산기, 아이템 구매 콘솔 프로그램을 만듭니다.
03

자료구조와 알고리즘

데이터를 효율적으로 저장하고 처리하는 방법을 배웁니다.

배열·리스트Dictionary탐색·정렬
  • 스택, 큐, 해시 테이블
  • 시간 복잡도와 공간 복잡도 기초
  • 문제를 작은 단계로 나누어 해결하기
실습: 인벤토리 자료구조와 아이템 검색·정렬 기능을 구현합니다.
04

Unity 엔진 기초

게임 오브젝트와 컴포넌트 구조를 이해하고 스크립트로 제어합니다.

Unity 6PrefabMonoBehaviour
  • Scene, GameObject, Component, Transform
  • Inspector, Prefab, Asset 관리
  • Start와 Update 생명주기
실습: 바닥, 캐릭터, 카메라가 있는 3D 테스트 장면을 만듭니다.
05

3D 게임 제작 기초

공간 이동과 물리 작동 방식을 익힙니다.

TransformRigidbodyCollider
  • 이동, 회전, 점프, 카메라 추적
  • Collision과 Trigger의 차이
  • 조명, 머티리얼, 애니메이션 기초
실습: 키보드로 움직이고 장애물과 충돌하는 캐릭터를 구현합니다.
06

핵심 게임 시스템

게임에서 반복적으로 쓰이는 기능을 모듈 단위로 구현합니다.

이동전투체력아이템
  • 캐릭터 이동과 상태 관리
  • 공격, 피격, 체력, 사망 처리
  • 아이템 획득과 인벤토리
실습: 적을 공격하고 아이템을 획득하는 미니 게임을 만듭니다.
07

UI와 사용자 경험

플레이어가 게임 상태를 쉽게 이해하고 조작하도록 화면을 구성합니다.

CanvasTextMeshPro
  • 메인 메뉴, 일시 정지, 설정 화면
  • 체력바, 점수, 알림 표시
  • 버튼 이벤트와 화면 전환
실습: 시작·설정·게임 오버 화면을 제작합니다.
08

게임 AI와 NPC

NPC가 상황에 따라 판단하고 행동하도록 구현합니다.

FSMNavMesh경로 탐색
  • FSM: 대기·추적·공격 상태 전환
  • NavMesh 기반 이동과 추적
  • 거리와 체력에 따른 행동 결정
실습: 플레이어를 발견하면 추적하고 가까워지면 공격하는 적 AI를 만듭니다.
09

데이터 저장과 구조 설계

게임 진행 상황을 저장하고 관리하기 쉬운 코드 구조를 만듭니다.

JSON세이브설계
  • PlayerPrefs와 JSON 방식 이해
  • 세이브·로드와 설정값 저장
  • 클래스 역할 분리와 이벤트 구조
실습: 최고 점수와 설정값을 저장하고 불러옵니다.
10

Git과 GitHub 협업

코드 변경 이력을 관리하고 협업하는 방법을 익힙니다.

GitGitHubREADME
  • commit, push, pull, branch, merge
  • .gitignore로 불필요한 Unity 파일 제외
  • 이슈와 작업 단위 관리
실습: Unity 프로젝트를 GitHub에 올리고 기능별 커밋을 남깁니다.
11

개인 게임 프로젝트

배운 기술을 하나의 플레이 가능한 게임으로 연결합니다.

기획구현테스트
  • 게임 목표와 핵심 재미 정의
  • 필수 기능과 선택 기능 구분
  • 빌드, 테스트, 버그 수정, 배포
실습: 1~2개 스테이지의 3D 액션 또는 퍼즐 게임을 완성합니다.
12

팀 프로젝트

역할을 나누고 문제를 해결하며 결과물을 통합합니다.

협업코드 리뷰문서화
  • 기획·클라이언트·아트 역할과 일정 합의
  • 브랜치 규칙과 작업 절차 수립
  • 정기 빌드와 통합 테스트
실습: 2~4명 팀으로 작은 게임을 만들고 본인의 기여를 기록합니다.
13

포트폴리오 제작

무엇을 만들었는지뿐 아니라 문제를 어떻게 해결했는지 보여줍니다.

GitHub시연 영상기술 문서
  • 프로젝트 소개, 역할, 개발 기간
  • 핵심 기능과 기술적 의사결정
  • 영상, 스크린샷, 실행 파일 또는 체험 링크
실습: 대표 프로젝트 2개를 선정해 README와 시연 영상을 정리합니다.
14

이력서와 기술 면접

채용 공고에 맞춰 역량을 설명하고 코드의 동작 원리를 말할 수 있어야 합니다.

이력서자기소개서면접
  • C#, 객체지향, 자료구조, 알고리즘 복습
  • Unity 생명주기, 물리, 최적화 질문 준비
  • 오류 원인과 해결 과정 정리
실습: 프로젝트별 예상 질문 10개와 답변을 작성합니다.
15

게임 개발 직무 지원

회사별 요구 기술을 비교하고 지원과 피드백을 반복합니다.

채용 공고지원 관리면접
  • 게임 회사와 관련 직무 조사
  • 요구 기술에 맞춰 서류와 포트폴리오 수정
  • 면접 결과를 기록하고 부족한 역량 보완
실습: 회사, 마감일, 요구 기술, 지원 상태를 표로 관리합니다.

1년 취업 준비 일정

졸업까지 약 1년이 남았다는 가정의 예시입니다. 현재 실력과 학사 일정에 맞춰 조정하세요.

  • 콘솔 프로그램 2~3개 제작
3~4개월

Unity와 3D 기초

5~6개월

게임 시스템과 AI

  • 전투·체력·아이템·UI
  • NPC 상태 머신과 추적
  • 저장·불러오기
7~8개월

개인 프로젝트 완성

팀 프로젝트와 포트폴리오

지원과 면접 준비

  • 이력서·자기소개서 작성
  • 기술 면접과 코딩 테스트
  • 지원 결과 분석 및 개선
주간 학습 예시: 전공·코딩 기초 5시간, Unity 실습 7시간, 개인 프로젝트 5시간, 복습·문서화 2시간. 무리한 시간표보다 매주 작동하는 결과물을 남기는 것이 중요합니다.

실무에서 기억할 핵심 원칙

  • 완성 우선: 기능이 많은 미완성 게임보다 작더라도 끝까지 플레이할 수 있는 게임이 낫습니다.
  • 코드 설명: 복사한 코드에서 끝내지 말고 각 스크립트의 역할과 원리를 설명할 수 있어야 합니다.
  • 문제 해결 기록: 오류, 원인, 해결 방법을 기록하면 면접에서 활용할 기술 사례가 됩니다.
  • 작게 나누어 개발: 큰 기능을 이동, 입력, 충돌, 상태 관리처럼 작은 단위로 나누어 구현하고 테스트합니다.
  • 채용 공고 역산: 관심 기업의 실제 요구 기술을 확인해 학습 우선순위를 조정합니다.
  • AI 도구는 보조 수단: 생성된 코드의 오류, 성능, 라이선스와 보안 문제를 직접 검토합니다.
