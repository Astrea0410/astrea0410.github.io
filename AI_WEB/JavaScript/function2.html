JavaScript 함수(Function) 정리
예제 8-10 ~ 8-12

함수를 만들고, 버튼으로 실행하고, 값을 계산하고, 브라우저가 미리 만들어 둔 함수까지 한 번에 익힙니다.

예제8-10 이벤트 함수 예제8-11 함수 계산 예제8-12 내장 함수 한눈에 비교

원문 페이지에서는 화면에 보이는 내용만 확인할 수 있어서, 아래 코드는 그 화면과 동작에 맞춰 다시 구성한 것입니다. 변수 이름이나 경고창 문구는 원본과 조금 다를 수 있지만 개념과 동작 방식은 같습니다.

예제 8-10 이벤트 함수

버튼을 누르는 순간, 미리 만들어 둔 함수가 실행됩니다.

이 예제에서 배우는 것
① 함수를 만드는 방법(function 이름() { }) ② 버튼 클릭(onclick)과 함수를 연결하는 방법

직접 눌러 보기

아직 아무것도 누르지 않았습니다.

전체 코드

<script>
  //버튼 클릭 이벤트
  function clickMessage() {
    alert("버튼이 눌렸습니다!");
  }
</script>

<h1>JavaScript 이벤트함수(Function)</h1>
<button onclick="clickMessage()">눌러주세요</button>

한 줄씩 이해하기

  1. <script> ... </script>
    이 태그 안에 적은 것은 HTML이 아니라 JavaScript 코드입니다. 브라우저가 이 부분을 만나면 자바스크립트로 읽습니다.
  2. //버튼 클릭 이벤트
    //로 시작하는 줄은 주석입니다. 사람이 읽으라고 쓰는 메모이고, 컴퓨터는 무시합니다.
  3. function clickMessage() { ... }
    함수 만들기(선언)입니다. clickMessage는 내가 붙인 함수 이름이고, 중괄호 { } 안에 "할 일"을 적습니다. 만들기만 하면 실행되지 않고, 누군가 이름을 불러 줘야 일합니다.
  4. alert("버튼이 눌렸습니다!");
    화면에 경고창(알림창)을 띄우는 내장 함수입니다. 따옴표 안의 글자가 창에 표시됩니다. 문장 끝의 ;(세미콜론)은 "여기까지가 한 문장"이라는 표시입니다.
  5. onclick="clickMessage()"
    이벤트 연결입니다. "이 버튼이 클릭되면 clickMessage()를 실행해라"라는 뜻입니다. 여기서 이름 뒤의 괄호 ()가 함수를 실행(호출)하라는 신호입니다.
핵심 정리 함수는 "이름 붙인 작업 묶음"입니다. 선언은 작업을 만들어 두는 것, 호출은 그 작업을 실제로 시키는 것입니다. 버튼 클릭 같은 사용자 행동을 이벤트라고 부릅니다.
자주 하는 실수 함수 이름의 대소문자가 선언과 호출에서 다르면 실행되지 않습니다. clickMessage와 clickmessage는 서로 다른 이름입니다. 오류가 나면 F12 키로 개발자 도구의 Console 탭을 확인해 보세요.

예제 8-11 함수 계산

입력칸의 값을 함수가 읽어서 더한 뒤, 결과를 화면에 돌려줍니다.

이 예제에서 배우는 것
① 입력칸의 값 가져오기(getElementById, value) ② 글자를 숫자로 바꾸기(parseInt) ③ 계산 결과를 화면에 넣기

직접 계산해 보기

두 개의 정수를 입력하세요.




전체 코드

<script>
  function calcSum() {
    var a = parseInt(document.getElementById("num1").value);
    var b = parseInt(document.getElementById("num2").value);
    var sum = a + b;
    document.getElementById("sumResult").value = sum;
  }
</script>

<h3>함수 계산 결과</h3>
<h4>두개의 정수를 입력하세요.</h4>
정수 입력1: <input type="text" id="num1"><br>
정수 입력2: <input type="text" id="num2"><br>
<button onclick="calcSum()">합계 계산</button><br>
합계: <input type="text" id="sumResult" readonly>

한 줄씩 이해하기

  1. <input type="text" id="num1">
    글자를 입력하는 칸입니다. id는 이 칸의 이름표(주민번호처럼 하나뿐인 이름)이고, 자바스크립트가 이 이름표로 칸을 찾아갑니다.
  2. document.getElementById("num1")
    "문서(document)에서 id가 num1인 요소를 찾아와라"라는 뜻입니다.
  3. .value
    찾아온 입력칸 안에 들어 있는 값을 꺼냅니다. 반대로 .value = 값처럼 쓰면 칸에 값을 넣을 수도 있습니다.
  4. parseInt( ... )
    입력칸에서 꺼낸 값은 숫자처럼 보여도 글자(문자열)입니다. parseInt가 이것을 진짜 정수로 바꿔 줍니다.
  5. var a = ...
    var는 값을 담아 두는 상자(변수)를 만드는 말입니다. 상자 이름 a, b에 각각 첫 번째, 두 번째 숫자를 보관합니다.
  6. var sum = a + b;
    두 숫자를 더해서 sum 상자에 담습니다.
  7. document.getElementById("sumResult").value = sum;
    결과 칸을 찾아서 그 안에 합계를 써 넣습니다. 결과 칸의 readonly는 사용자가 직접 고치지 못하게 막는 속성입니다.
핵심 정리 함수의 기본 흐름은 ① 값 가져오기 → ② 계산하기 → ③ 결과 보여주기입니다. 대부분의 프로그램이 이 세 단계의 반복입니다.
자주 하는 실수 parseInt 없이 더하면 "3"과 "5"가 "35"로 이어 붙습니다(문자열 연결). 또 숫자가 아닌 글자를 넣으면 결과가 NaN("숫자가 아님")으로 나옵니다. 위 실습에서 직접 확인해 보세요.

예제 8-12 내장 함수 (alert, confirm, prompt)

내가 만들지 않아도 브라우저가 이미 갖고 있는, 바로 쓸 수 있는 함수들입니다.

이 예제에서 배우는 것
① 알림창 alert, 확인창 confirm, 입력창 prompt의 차이 ② 창이 돌려주는 값을 변수에 받아 쓰는 방법

직접 눌러 보기

단추를 누르면 경고창이 나타납니다.

결과가 여기에 표시됩니다.

전체 코드

<script>
  function useAlert() {
    alert("안녕하세요! 알림창입니다.");
  }

  function useConfirm() {
    var ok = confirm("정말 진행할까요?");
    if (ok) {
      document.getElementById("out12").innerHTML = "확인을 눌렀습니다 (true)";
    } else {
      document.getElementById("out12").innerHTML = "취소를 눌렀습니다 (false)";
    }
  }

  function usePrompt() {
    var name = prompt("이름을 입력하세요", "홍길동");
    if (name != null) {
      document.getElementById("out12").innerHTML = name + "님, 반갑습니다!";
    }
  }
</script>

<h3>유용한 함수</h3>
<h4>단추를 누르면 경고창이 나타납니다.</h4>
<button onclick="useAlert()">alert 실행</button>
<button onclick="useConfirm()">confirm 실행</button>
<button onclick="usePrompt()">prompt 실행</button>
<div id="out12"></div>

세 함수 비교

함수창의 모양돌려주는 값언제 쓰나요?
alert("글")글자 + [확인]없음알려주기만 할 때
confirm("글")글자 + [확인] [취소]확인 true / 취소 false"정말 삭제할까요?"처럼 의사를 물을 때
prompt("글", "기본값")글자 + 입력칸 + [확인] [취소]입력한 글자 / 취소하면 null사용자에게 값을 직접 입력받을 때

한 줄씩 이해하기

  1. var ok = confirm("정말 진행할까요?");
    confirm 창이 뜨고, 사용자가 누른 버튼에 따라 true 또는 false가 ok 상자에 담깁니다. 이처럼 함수가 일을 마치고 내놓는 결과를 반환값이라고 합니다.
  2. if (ok) { ... } else { ... }
    "만약 ok가 true라면 앞부분을, 아니라면 else 뒷부분을 실행해라"라는 조건문입니다. (다음 예제 8-13에서 자세히 배웁니다.)
  3. prompt("이름을 입력하세요", "홍길동")
    첫 번째 글자는 안내 문구, 두 번째는 입력칸에 미리 채워 둘 기본값입니다. 쉼표(,)로 구분해서 함수에 값을 넘겨 주는데, 이 값을 인자(매개변수)라고 부릅니다.
  4. if (name != null)
    !=는 "같지 않다"라는 뜻입니다. 사용자가 [취소]를 누르면 null이 돌아오므로, 취소가 아닐 때만 결과를 보여 주도록 막아 둔 것입니다.
  5. innerHTML
    요소 안의 내용을 바꾸는 속성입니다. 여기서는 결과 상자(<div id="out12">)에 글자를 써 넣는 데 사용했습니다.
핵심 정리 함수는 값을 받아서(인자) → 일을 하고 → 결과를 돌려줄(반환값) 수 있습니다. alert는 돌려주는 값이 없고, confirm과 prompt는 돌려주는 값을 변수에 받아서 다음 동작을 결정합니다.
자주 하는 실수 prompt가 돌려주는 값은 숫자를 입력해도 글자입니다. 계산하려면 예제 8-11처럼 parseInt로 바꿔야 합니다. 또 이 창들은 닫을 때까지 다른 화면 조작이 멈추므로 꼭 필요한 곳에만 사용합니다.
