② 내부 JavaScript

HTML 문서 내부의 <script> 태그에 JavaScript를 직접 작성하는 방식입니다.

내부 JavaScript 실행 결과가 여기에 표시됩니다.

▶ 방식: 내부 JavaScript

③ 인라인 JavaScript

HTML 요소의 이벤트 속성에 JavaScript를 직접 작성합니다.

버튼을 클릭하면 결과가 표시됩니다.

▶ 방식: 인라인 JavaScript
