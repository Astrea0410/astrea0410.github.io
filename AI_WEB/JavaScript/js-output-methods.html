자바스크립트 출력 방법 4가지

예제 8-6 · document.write(), innerHTML, alert(), console.log()

한눈에 보기

방법출력 위치주로 쓰는 경우
document.write()HTML 문서 본문에 직접간단한 테스트 (실제 개발에서는 거의 사용 안 함)
innerHTML선택한 요소 안쪽화면의 특정 부분을 바꿀 때 (가장 많이 사용)
window.alert()팝업 경고창사용자에게 바로 알리고 싶을 때
console.log()개발자 도구 콘솔값 확인, 오류 찾기(디버깅)

예제 코드

4가지 출력 방법을 한 파일에서 차례로 실행하는 코드입니다. 주석에 각 줄이 하는 일을 적었습니다.

<!-- 문서 형식을 HTML5로 선언 -->
<!DOCTYPE html>
<html>
<head>
    <title>예제8-6 출력문</title>
</head>
<body>
<h1>JavaScript Output</h1>
<!-- innerHTML로 내용을 채울 빈 단락. id로 찾아서 사용 -->
<p id="output"></p>
    <script>
        // 1. 문서(body)에 문자열을 그대로 써 넣는다
        document.write("outPut1:write");

        // 2. id="output"인 요소를 찾아 그 안의 내용을 바꾼다
        document.getElementById("output").innerHTML = "outPut2:innerHTML";

        // 3. 팝업 창으로 메시지를 띄운다 (확인을 누를 때까지 멈춤)
        window.alert("outPut3:alert");

        // 4. 개발자 도구(F12)의 Console 탭에 기록한다
        console.log("outPut4:console");
    </script>
</body>
</html>

실행 결과와 실행 순서

  1. document.write가 먼저 실행되어 화면에 outPut1:write가 찍힙니다.
  2. innerHTML이 <p id="output"> 안에 outPut2:innerHTML을 넣습니다.
  3. alert 창이 뜨고, [확인]을 누를 때까지 다음 코드로 넘어가지 않습니다.
  4. [확인] 후 console.log가 콘솔에 outPut4:console을 기록합니다. 화면에는 보이지 않으니 F12를 눌러 확인하세요.

방법별 설명과 직접 실행

1. document.write()

HTML 문서에 문자열을 그대로 써 넣습니다. HTML 태그도 함께 쓸 수 있습니다. 배우기 쉽지만, 실제 개발에서는 잘 쓰지 않습니다.

주의: 페이지 로딩이 끝난 뒤에 document.write()를 실행하면 기존 문서 전체가 지워지고 그 내용만 남습니다. 아래에서 두 경우를 비교해 보세요.

직접 실행해 보기

2. innerHTML

getElementById("output")으로 요소를 찾고, innerHTML에 값을 넣으면 그 요소의 내용만 바뀝니다. 문서의 다른 부분은 그대로 유지되므로 화면 출력에 가장 많이 쓰입니다. 태그가 포함된 문자열을 넣으면 태그로 해석됩니다. 단순한 글자만 넣을 때는 textContent도 사용할 수 있습니다.

직접 실행해 보기

3. window.alert()

화면 위에 팝업 경고창을 띄웁니다. 사용자가 [확인]을 누를 때까지 페이지의 다른 동작이 멈추기 때문에, 꼭 필요한 알림에만 사용합니다. window.는 생략하고 alert()만 써도 됩니다.

직접 실행해 보기

4. console.log()

브라우저 개발자 도구(F12)의 Console 탭에 값을 출력합니다. 사용자 화면에는 나타나지 않아서, 변수 값이 맞는지 확인하는 디버깅용으로 씁니다.

직접 실행해 보기

위 검은 상자는 이해를 돕기 위한 모형입니다. 실제 출력은 F12 → Console 탭에서 볼 수 있습니다.
