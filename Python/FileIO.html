파일 입출력 (File I/O)

파일에 데이터를 저장하고 다시 읽어 프로그램이 끝난 뒤에도 정보를 보관합니다.

Python 학습 자료 다음: 자료구조
01 / FILES

파일 입출력이란?

변수에 저장한 값은 프로그램이 종료되면 사라지지만, 파일에 기록한 데이터는 저장 장치에 남습니다. 파일 작업은 파일 열기, 읽기 또는 쓰기, 닫기의 순서로 이루어집니다.

02 / MODES

파일 열기 모드

모드기능주의점
"r"읽기파일이 없으면 오류
"w"쓰기기존 파일 내용을 덮어씀
"a"뒤에 추가기존 내용을 유지하고 끝에 기록
"x"새 파일 생성같은 이름의 파일이 있으면 오류

텍스트 파일에서는 인코딩을 명시하면 한글을 일관되게 처리하기 쉽습니다. 상대 경로를 사용할 때 파일은 현재 작업 폴더를 기준으로 읽고 씁니다.

03 / WRITE

with open()으로 쓰기

with 블록을 사용하면 블록이 끝날 때 파일이 자동으로 닫힙니다. "w" 모드는 기존 파일을 덮어쓰므로 주의하세요.

with open("memo.txt", "w", encoding="utf-8") as file:
    file.write("Python 파일 입출력\n")
    file.write("첫 번째 메모입니다.\n")
04 / READ

파일 읽기와 내용 추가

read()는 전체 내용을 읽고, readline()은 한 줄, readlines()는 줄 목록을 반환합니다. 반복문으로 파일을 순회하면 큰 파일도 줄 단위로 처리할 수 있습니다.

with open("memo.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip())

with open("memo.txt", "a", encoding="utf-8") as file:
    file.write("추가된 메모\n")
05 / STUDENT RECORD

간단한 점수 기록 예제

데이터를 일정한 형식으로 기록하면 다시 읽어와 계산할 수 있습니다. 아래 예제는 한 줄에 이름과 점수를 저장하고 평균을 계산합니다.

with open("scores.txt", "w", encoding="utf-8") as file:
    file.write("민지,95\n")
    file.write("준호,88\n")

scores = []
with open("scores.txt", "r", encoding="utf-8") as file:
    for line in file:
        name, score = line.strip().split(",")
        scores.append(int(score))

print("평균:", sum(scores) / len(scores))
