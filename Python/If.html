Python Programming · Week 03

조건문 (if)

조건의 참과 거짓에 따라 실행 흐름을 선택하고, 비교·논리 연산자로 조건을 만들어 봅니다.

Python 학습 자료 다음: 반복문
01 / CONDITIONS

조건문과 들여쓰기

if는 조건식이 참일 때 코드 블록을 실행합니다. Python에서는 콜론 다음 줄을 들여써 블록을 표시합니다. 들여쓰기는 보통 공백 4칸을 사용합니다.

score = 95

if score >= 90:
    print("A학점")

print("프로그램 종료")
02 / COMPARISON

비교 연산자

연산자의미예
==같다a == b
!=다르다a != b
>, <크다, 작다a > b
>=, <=크거나 같다, 작거나 같다score >= 60
 
a = 10
b = 20

print(a == b)  # False
print(a != b)  # True
print(a < b)   # True
03 / IF ELSE

if, else, elif

조건이 두 가지라면 if-else, 여러 범위를 차례로 검사하려면 if-elif-else를 사용합니다. 위에서부터 검사하므로 범위 조건의 순서가 중요합니다.

score = 87

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(grade)
04 / LOGIC

논리 연산자와 중첩 조건

and는 모든 조건이 참일 때, or는 하나라도 참일 때 참입니다. not은 참과 거짓을 반대로 바꿉니다.

age = 22
member = True

if age >= 20 and member:
    print("입장 가능합니다.")

subjects = ["Python", "AI", "Web"]
if "Python" in subjects:
    print("Python 수강 중입니다.")
05 / PRACTICE

입력값으로 짝수·홀수 판별

input()의 결과는 문자열이므로 숫자 계산 전에 int()로 변환합니다.

number = int(input("정수를 입력하세요: "))

if number % 2 == 0:
    print("짝수")
else:
    print("홀수")
