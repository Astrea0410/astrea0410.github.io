여러 데이터를 함께 저장하는 리스트, 튜플, 딕셔너리의 구조와 사용법을 익힙니다.

Python 학습 자료 다음: 메소드
01 / COLLECTIONS

컬렉션이란?

컬렉션은 여러 값을 하나의 변수에 저장하고 함께 다루는 자료형입니다. 저장 순서와 수정 가능 여부에 따라 알맞은 자료형을 선택합니다.

자료형순서수정주요 특징
list있음가능중복을 허용하는 값의 목록
tuple있음불가변경하지 않을 값의 묶음
dict삽입 순서 유지가능키와 값의 쌍
02 / LIST

리스트: 순서가 있고 수정 가능한 목록

인덱스는 0부터 시작합니다. 슬라이싱의 끝 인덱스는 포함되지 않으며, 리스트는 추가·수정·삭제할 수 있습니다.

scores = [90, 80, 100, 95]
print(scores[0])
print(scores[-1])
print(scores[1:3])

scores[1] = 85
scores.append(88)
scores.insert(1, 70)
scores.remove(70)
print(scores)
03 / TUPLE

튜플: 생성 후 수정할 수 없는 묶음

튜플은 순서를 유지하고 인덱스로 접근할 수 있지만 항목을 바꿀 수 없습니다. 변경되지 않아야 하는 좌표나 날짜 같은 값을 표현할 때 유용합니다.

birthday = (2006, 5, 18)
print(birthday[0])
print(len(birthday))

# birthday[0] = 2007  # TypeError: 튜플은 수정할 수 없습니다.
04 / DICTIONARY

딕셔너리: 키와 값의 쌍

딕셔너리는 키를 이용해 값을 찾습니다. 키는 중복될 수 없고, 값을 추가하거나 변경할 수 있습니다.

student = {
    "name": "민지",
    "major": "AI소프트웨어과",
    "grade": 1
}

print(student["name"])
student["grade"] = 2
student["gpa"] = 4.2

for key, value in student.items():
    print(f"{key}: {value}")
05 / NESTED DATA

리스트와 딕셔너리 함께 사용하기

여러 학생처럼 같은 구조의 레코드를 다룰 때 리스트 안에 딕셔너리를 저장하면 편리합니다.

students = [
    {"name": "민지", "python": 95, "ai": 90},
    {"name": "준호", "python": 88, "ai": 84},
]

for student in students:
    average = (student["python"] + student["ai"]) / 2
    print(student["name"], average)
