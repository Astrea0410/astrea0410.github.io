Python Programming · Week 05

함수 (Function)

기능을 함수로 묶어 재사용하고, 매개변수와 반환값으로 데이터를 주고받습니다.

Python 학습 자료 다음: 컬렉션 자료형
01 / INTRODUCTION

함수란?

함수는 특정 작업을 수행하도록 이름을 붙여 둔 코드의 묶음입니다. 반복되는 코드를 재사용하고, 프로그램을 기능별로 나누어 읽고 관리하기 쉽게 합니다.

def hello():
    print("안녕하세요.")

hello()
02 / PARAMETERS

매개변수와 인수

함수 정의의 매개변수(parameter)는 입력값을 받는 변수이고, 호출할 때 전달하는 값을 인수(argument)라고 합니다. 기본값과 키워드 인수도 사용할 수 있습니다.

def greet(name="학생"):
    print(f"{name}님, 반갑습니다.")

greet()
greet("민지")

def introduce(name, age):
    print(f"{name}, {age}세")

introduce(age=20, name="민지")
03 / RETURN

반환값 return

return은 함수의 결과를 호출한 곳으로 돌려줍니다. 값을 반환하지 않는 함수는 기본적으로 None을 반환합니다.

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

def calculate(a, b):
    return a + b, a - b

total, difference = calculate(20, 10)
print(total, difference)
04 / SCOPE

지역 변수와 전역 변수

함수 안에서 만든 변수는 지역 변수이며 함수 바깥에서는 사용할 수 없습니다. 필요한 값은 매개변수로 전달하고 결과는 반환하는 방식이 명확합니다.

def square(number):
    result = number * number
    return result

print(square(5))
# result는 함수 내부의 지역 변수입니다.
05 / COMPOSITION

함수 조합: 평균과 학점

작은 기능을 각각 함수로 만든 뒤 함께 사용하면 전체 프로그램을 이해하기 쉽습니다.

def average(scores):
    return sum(scores) / len(scores)

def grade(score):
    if score >= 90:
        return "A"
    if score >= 80:
        return "B"
    if score >= 70:
        return "C"
    if score >= 60:
        return "D"
    return "F"

scores = [90, 85, 100]
avg = average(scores)
print(f"평균: {avg:.1f}, 학점: {grade(avg)}")
06 / BUILT-INS

자주 사용하는 내장 함수

len(), sum(), min(), max(), round(), sorted() 등은 별도 정의 없이 바로 사용할 수 있습니다.

scores = [90, 80, 100]
print(len(scores))
print(sum(scores))
print(min(scores), max(scores))
print(round(sum(scores) / len(scores), 2))
print(sorted(scores))
