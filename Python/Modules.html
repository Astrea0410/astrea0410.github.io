모듈 (Module)

기능을 파일 단위로 나누고 필요한 모듈을 가져와 코드를 재사용합니다.

Python 학습 자료 이전: 자료구조
01 / MODULE

모듈이란?

모듈은 함수, 클래스, 변수 등을 담은 Python 파일(.py)입니다. 기능을 여러 파일로 나누면 코드를 재사용하고 관리하기 쉬워집니다.

표준 라이브러리

Python 설치에 포함되어 바로 사용할 수 있는 모듈입니다.

사용자 모듈

직접 작성한 Python 파일을 가져와 사용할 수 있습니다.

외부 패키지

별도로 설치해 사용하는 제3자 라이브러리입니다.

02 / IMPORT

import 사용법

모듈 전체를 가져오거나 필요한 이름만 선택해서 가져올 수 있습니다. 별칭을 지정하면 짧은 이름으로 사용할 수 있습니다.

import math
print(math.sqrt(25))

from math import pi, ceil
print(pi)
print(ceil(3.2))

import random as rng
print(rng.randint(1, 6))
03 / STANDARD LIBRARY

자주 쓰는 표준 모듈

모듈용도예시
math수학 함수와 상수제곱근, 원주율
random무작위 값 생성주사위, 임의 선택
datetime날짜와 시간현재 시각, 날짜 계산
pathlib파일 경로 처리폴더와 파일 경로
csv, json데이터 파일 읽기·쓰기표 형식 및 JSON 데이터
 
from datetime import datetime
import random

print(datetime.now().strftime("%Y-%m-%d"))
print(random.choice(["가위", "바위", "보"]))
04 / YOUR MODULE

나만의 모듈 만들기

같은 폴더에 calculator.py와 실행 파일을 만들면 모듈을 가져올 수 있습니다. 실행 파일 이름을 모듈 이름과 똑같이 짓지 마세요.

# calculator.py
def add(a, b):
    return a + b

# main.py
import calculator

print(calculator.add(10, 20))
05 / PACKAGES

패키지와 외부 라이브러리

패키지는 관련 모듈을 폴더 구조로 묶어 관리합니다. 외부 패키지는 프로젝트의 Python 환경에 설치해 사용하며, 설치한 라이브러리 이름과 모듈 import 이름이 다를 수 있습니다.

# 예: 현재 Python 환경에 외부 패키지 설치
python -m pip install 패키지이름
