Python Programming · Week 02

자료형 (Data Type)

Python이 다루는 값의 종류를 알아보고, 각 자료형의 특징과 기본 사용법을 실습합니다.

Python 학습 자료 실습 코드로 이동
01 / OVERVIEW

자료형이란?

자료형(Data Type)은 값의 종류와 그 값을 다루는 방법을 나타냅니다. 예를 들어 나이는 정수, 키는 실수, 이름은 문자열, 합격 여부는 논리형으로 표현할 수 있습니다.

자료형을 알면 값에 알맞은 연산과 저장 방법을 선택할 수 있습니다. Python에서는 type()을 사용해 값이나 변수의 자료형을 확인합니다.

age = 20
height = 175.3
name = "민지"
passed = True

print(type(age))
print(type(height))
print(type(name))
print(type(passed))
02 / DATA TYPES

Python의 대표 자료형 8가지

자료형 설명 예시
int 정수 10, -5, 0
float 실수 3.14, -2.5
str 문자열 "Python", 'AI'
bool 논리값 True, False
list 순서가 있고 수정 가능한 여러 값 [10, 20, 30]
tuple 순서가 있고 수정할 수 없는 여러 값 (10, 20, 30)
dict 키와 값으로 이루어진 데이터 {"name": "민지"}
set 중복을 허용하지 않는 값의 모음 {1, 2, 3}
03 / NUMBERS

정수 int와 실수 float

정수와 실수는 숫자 계산에 사용합니다. 정수끼리 나누기 연산자 /를 사용하면 결과는 실수가 될 수 있습니다. //는 몫, %는 나머지를 구합니다.

a = 20
b = 7

print(a + b)   # 27
print(a / b)   # 나눗셈 결과
print(a // b)  # 몫: 2
print(a % b)   # 나머지: 6
print(a ** 2)  # 거듭제곱: 400

pi = 3.141592
print(round(pi, 2))  # 3.14
04 / STRINGS

문자열 str

문자열은 따옴표로 감싸서 만듭니다. 인덱스는 0부터 시작하고, 음수 인덱스는 뒤에서부터 셉니다. 슬라이싱의 끝 인덱스는 결과에 포함되지 않습니다.

word = "Python"

print(len(word))  # 6
print(word[0])    # P
print(word[-1])   # n
print(word[0:3])  # Pyt
print(word[2:])   # thon
05 / COLLECTIONS

여러 값을 담는 자료형

리스트 list

값에 순서가 있으며 항목을 추가하거나 수정할 수 있습니다.

scores = [90, 85, 100]
scores[1] = 88
scores.append(77)
print(scores)

튜플 tuple

값에 순서가 있지만 만든 뒤 항목을 수정할 수 없습니다.

colors = ("red", "green", "blue")
print(colors[0])
print(len(colors))

딕셔너리 dict

키(key)로 값(value)을 찾습니다. 키는 중복될 수 없습니다.

student = {
    "name": "민지",
    "grade": 1
}
student["major"] = "AI"
print(student["name"])

집합 set

중복을 제거할 때 유용합니다. 항목에 순서가 있다고 가정하지 않습니다.

numbers = {1, 2, 2, 3}
numbers.add(4)
print(numbers)
print(len(numbers))  # 4
06 / TYPE CONVERSION

자료형 확인과 변환

int(), float(), str() 등으로 값을 다른 자료형으로 변환할 수 있습니다. 변환할 수 없는 문자열을 숫자로 바꾸면 ValueError가 발생하므로 입력값을 확인해야 합니다.

text = "100"
number = int(text)

print(number + 50)     # 150
print(str(number) + "점")  # 100점
print(float(100))      # 100.0
print(int(3.99))       # 3

int(3.99)는 반올림이 아니라 소수 부분을 버립니다. 반올림이 필요하면 round()를 사용하세요.

07 / EXAMPLE

종합 예제: 학생 정보

딕셔너리와 리스트를 함께 사용해 학생 정보를 표현할 수 있습니다.

student = {
    "name": "민지",
    "major": "AI소프트웨어과",
    "grade": 1,
    "gpa": 4.35,
    "subjects": ["Python", "AI", "Web"],
    "scholarship": True
}

print(f"이름: {student['name']}")
print(f"학과: {student['major']}")
print(f"학년: {student['grade']}")
print(f"평점: {student['gpa']}")
print(f"과목: {', '.join(student['subjects'])}")
print(f"장학금 대상: {student['scholarship']}")
