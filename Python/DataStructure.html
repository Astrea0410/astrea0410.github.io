01 / ALGORITHM

알고리즘과 자료구조

알고리즘은 문제를 해결하는 단계별 절차이고, 자료구조는 데이터를 저장하고 효율적으로 다루는 방법입니다. 문제의 요구에 맞는 구조를 선택하면 처리 과정을 단순하게 만들 수 있습니다.

02 / LIST & ARRAY

리스트와 배열

Python 리스트는 여러 값을 순서대로 저장하며 다양한 종류의 값도 담을 수 있습니다. array 모듈의 배열은 지정한 숫자형 값을 저장합니다.

numbers = [10, 20, 30]
numbers.append(40)
print(numbers[0], numbers[-1])
print(sum(numbers))

from array import array
values = array("i", [10, 20, 30])
values.append(40)
print(values)
03 / STACK

스택: 마지막에 넣은 것을 먼저 꺼내기

스택은 LIFO(Last In, First Out) 구조입니다. 리스트의 append()와 pop()으로 간단히 만들 수 있습니다.

stack = []
stack.append("첫 번째")
stack.append("두 번째")

last_item = stack.pop()
print(last_item)  # 두 번째
print(stack)
04 / QUEUE

큐: 먼저 들어온 것을 먼저 꺼내기

큐는 FIFO(First In, First Out) 구조입니다. 양쪽 끝에서 효율적으로 추가·삭제할 수 있는 collections.deque를 사용할 수 있습니다.

from collections import deque

queue = deque(["민지", "준호"])
queue.append("서연")

next_person = queue.popleft()
print(next_person)  # 민지
print(queue)
