01 / OOP

객체지향 프로그래밍이란?

객체지향 프로그래밍은 관련 데이터(속성)와 동작(메소드)을 객체 단위로 묶어 표현하는 방식입니다. 예를 들어 학생 객체는 이름·학번을 속성으로, 자기소개나 평균 계산을 메소드로 가질 수 있습니다.

캡슐화

데이터와 동작을 한 객체 안에 모아 관리합니다.

상속

기존 클래스의 기능을 물려받아 확장합니다.

다형성

같은 이름의 동작을 객체에 맞게 다르게 구현할 수 있습니다.

추상화

필요한 핵심 특성만 표현해 복잡한 세부사항을 단순화합니다.

02 / CLASS & INSTANCE

클래스와 객체 만들기

클래스는 객체를 만들기 위한 설계도이고, 클래스로 만든 각각의 실제 데이터를 인스턴스라고 합니다. 메소드의 첫 번째 매개변수 self는 호출한 인스턴스를 가리킵니다.

class Student:
    def __init__(self, name, major):
        self.name = name
        self.major = major

    def introduce(self):
        return f"{self.name} 학생은 {self.major} 전공입니다."

student = Student("민지", "AI소프트웨어과")
print(student.introduce())
03 / CONSTRUCTOR

생성자 __init__()

__init__()은 인스턴스가 만들어질 때 자동으로 호출되어 초기 속성을 설정합니다. 인스턴스별로 다른 데이터를 저장할 수 있습니다.

class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

shape = Rectangle(5, 3)
print(shape.area())
04 / INHERITANCE

상속과 메소드 재정의

상속을 사용하면 자식 클래스가 부모 클래스의 속성과 메소드를 활용할 수 있습니다. 같은 메소드 이름을 자식 클래스에서 다시 정의하면 동작을 재정의(override)합니다.

class Animal:
    def speak(self):
        return "소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return "멍멍!"

pet = Dog()
print(pet.speak())
05 / DESIGN

클래스 설계의 기초

클래스는 하나의 책임에 집중하도록 설계하고, 속성과 메소드 이름은 역할이 드러나게 정합니다. UML 클래스 다이어그램은 클래스 이름, 속성, 메소드와 클래스 간 관계를 시각적으로 나타냅니다.

class Course:
    def __init__(self, title):
        self.title = title
        self.students = []

    def enroll(self, student):
        self.students.append(student)

    def student_count(self):
        return len(self.students)
