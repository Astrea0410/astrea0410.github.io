01 / OVERVIEW

Python이란?

Python은 1991년 귀도 반 로섬이 공개한 고급 프로그래밍 언어입니다. 사람이 읽기 편한 문법과 폭넓은 라이브러리를 갖추고 있어 처음 코딩을 배우거나 빠르게 아이디어를 실험할 때 유용합니다.

Python 프로그램은 보통 .py 파일에 저장합니다. 코드를 실행하면 Python 실행 환경이 문장을 해석하고 동작을 수행합니다.

읽기 쉬운 문법

들여쓰기와 간결한 표현으로 코드의 구조를 파악하기 쉽습니다.

다양한 생태계

표준 라이브러리와 공개 패키지를 활용해 기능을 확장할 수 있습니다.

여러 운영체제에서 사용

Windows, macOS, Linux 등에서 같은 언어와 도구를 이용할 수 있습니다.

04 / FIRST PROGRAM

print()로 화면에 출력하기

print()는 전달한 값이나 계산 결과를 화면에 보여 줍니다. 문자열은 따옴표로 감싸고, 숫자는 따옴표 없이 쓸 수 있습니다.

print("Hello, Python!")
print("합계:", 10 + 20)
print(3.14)
print(type("3.14"))

실행 결과 예시: Hello, Python! · 합계: 30 · 3.14

05 / PRINT PRACTICE

문자열과 출력 형식 연습

줄바꿈과 탭

문자열 안의 특수 표기인 이스케이프 문자를 이용해 출력 모양을 바꿀 수 있습니다.

print("첫째 줄\n둘째 줄")
print("이름\t점수")
print("민지\t95")

구분자와 줄 끝 제어

sep는 여러 값 사이에 들어갈 문자열을, end는 출력 마지막에 붙일 문자열을 지정합니다.

print("2026", "11", "15", sep="-")
print("Python", end=" ")
print("기초")

실행 결과 예시: 2026-11-15 · Python 기초

f-string으로 값 끼워 넣기

문자열 앞에 f를 붙이면 중괄호 안에 변수나 계산식을 넣을 수 있습니다.

name = "민지"
score = 95

print(f"{name} 학생의 점수는 {score}점입니다.")
print(f"다음 시험 목표: {score + 5}점")

정렬과 소수점 자리

f-string 형식 지정으로 열 너비나 숫자의 소수점 자릿수를 정할 수 있습니다.

item = "Python"
price = 12.5

print(f"|{item:<10}|")
print(f"|{item:>10}|")
print(f"가격: {price:.2f}")
