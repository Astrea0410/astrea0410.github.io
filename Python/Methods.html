Python Programming · Week 07

자료형 메소드 (Methods)

자료형에 딸린 메소드를 호출해 문자열을 다듬고 컬렉션을 검색·수정합니다.

Python 학습 자료 다음: 클래스와 객체
01 / METHODS

메소드란?

메소드는 특정 자료형이 제공하는 기능입니다. 객체 뒤에 점을 찍고 메소드 이름과 괄호를 적어 호출합니다. 자료형마다 쓸 수 있는 메소드가 다릅니다.

text = "python"
print(text.upper())

items = [1, 2]
items.append(3)
print(items)
02 / STRING

문자열 메소드

문자열 메소드는 대소문자 변환, 공백 정리, 검색, 치환, 분리와 결합에 활용합니다. 문자열은 불변 자료형이므로 결과가 원본 문자열을 직접 바꾸지는 않습니다.

message = "  Hello Python  "
print(message.strip())
print(message.lower())
print(message.replace("Python", "AI"))
print("red,green,blue".split(","))
print("-".join(["2026", "11", "15"]))
print("Python".startswith("Py"))
03 / LIST

리스트 메소드

append()와 extend()는 항목을 추가하고, remove()와 pop()은 삭제합니다. sort()는 리스트 자체의 순서를 바꾸며, sorted()는 정렬된 새 리스트를 반환합니다.

scores = [90, 75, 100]
scores.append(88)
scores.extend([82, 95])
scores.remove(75)
last_score = scores.pop()
scores.sort()

print(scores)
print("삭제된 점수:", last_score)
print("내림차순 새 목록:", sorted(scores, reverse=True))
04 / DICT & SET

딕셔너리와 집합 메소드

student = {"name": "민지", "grade": 1}
print(student.get("name"))
student.update({"grade": 2, "major": "AI"})
removed = student.pop("grade")

tags = {"python", "ai"}
tags.add("web")
tags.discard("ai")
print(tags)

get()은 키가 없을 때 기본값을 지정할 수 있어 안전한 조회에 유용합니다. 집합은 add()로 추가하고 discard()로 항목을 제거할 수 있습니다.

05 / MUTABILITY

가변과 불변

리스트·딕셔너리·집합은 내용을 바꿀 수 있는 가변 자료형입니다. 문자열과 튜플은 불변 자료형이며, 값을 바꾸는 것처럼 보이는 연산은 새 값을 만듭니다.

numbers = [1, 2]
alias = numbers
alias.append(3)
print(numbers)  # 같은 리스트가 변경됨

word = "cat"
word = word.upper()  # 새 문자열을 변수에 다시 할당
print(word)
