반복문 (for · while)

같은 작업을 여러 번 실행하는 반복문과 반복 흐름을 제어하는 방법을 연습합니다.

Python 학습 자료 다음: 함수
01 / LOOPS

반복문이란?

for는 정해진 범위나 반복 가능한 자료의 항목을 순서대로 처리할 때, while은 조건이 참인 동안 반복할 때 사용합니다.

for

리스트, 문자열, range() 등의 항목을 차례대로 처리합니다.

while

조건을 검사하고 참인 동안 반복합니다. 반복 중 조건을 바꾸어 종료할 수 있게 해야 합니다.

02 / FOR & RANGE

for와 range()

range(stop)는 0부터 stop 직전까지, range(start, stop, step)은 지정한 간격의 정수를 만듭니다.

for number in range(1, 6):
    print(number)

for even in range(2, 11, 2):
    print(even)

subjects = ["Python", "AI", "Web"]
for subject in subjects:
    print(subject)
03 / WHILE

while 반복과 종료 조건

반복할 때마다 조건에 영향을 주는 값을 갱신하세요. 종료 조건이 바뀌지 않으면 반복이 끝나지 않을 수 있습니다.

count = 1
while count <= 5:
    print(count)
    count += 1

answer = ""
while answer != "q":
    answer = input("종료하려면 q를 입력하세요: ")
04 / FLOW CONTROL

break, continue, 중첩 반복

break는 반복문 전체를 끝내고, continue는 현재 회차의 남은 코드를 건너뜁니다.

for number in range(1, 10):
    if number == 5:
        continue
    if number == 8:
        break
    print(number)

for dan in range(2, 10):
    for number in range(1, 10):
        print(f"{dan} x {number} = {dan * number}")
05 / USEFUL PATTERNS

enumerate()와 합계

enumerate()는 반복하면서 인덱스와 값을 함께 제공합니다. 합계와 평균은 내장 함수로 간단히 구할 수 있습니다.

subjects = ["Python", "AI", "Web"]
for index, subject in enumerate(subjects, start=1):
    print(index, subject)

scores = [90, 85, 100, 95]
print("합계:", sum(scores))
print("평균:", sum(scores) / len(scores))
