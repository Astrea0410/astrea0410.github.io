Introduction to Information Technology · Chapter 10

인공지능과 최신 IT 기술

인공지능과 데이터 기술부터 클라우드, 사물인터넷, 확장현실까지 현재의 IT 기술과 활용 과제를 살펴봅니다.

IT개론 목차 핵심 정리와 생각해 보기
10.1 / ARTIFICIAL INTELLIGENCE

인공지능(AI)의 개념

인공지능(Artificial Intelligence, AI)은 컴퓨터 시스템이 데이터와 알고리즘을 이용해 인식, 예측, 추천, 언어 생성처럼 일반적으로 지능이 필요하다고 여겨지는 작업을 수행하도록 하는 기술과 연구 분야입니다. AI가 수행할 수 있는 작업과 성능은 사용하는 데이터, 모델, 목표와 환경에 따라 달라집니다.

인식

이미지에서 사물을 찾거나 음성 신호를 문자로 바꾸는 작업입니다.

예측과 분류

데이터의 패턴을 바탕으로 범주를 분류하거나 가능한 값을 예측합니다.

생성

학습한 패턴을 바탕으로 텍스트, 이미지, 오디오 등 새로운 결과를 만듭니다.

10.2 / MACHINE LEARNING & DEEP LEARNING

머신러닝과 딥러닝

머신러닝(Machine Learning)은 사람이 모든 규칙을 직접 작성하는 대신 데이터에서 패턴을 학습해 예측이나 판단에 활용하는 AI의 한 분야입니다. 딥러닝(Deep Learning)은 여러 층의 신경망을 이용하는 머신러닝 방법입니다.

인공지능포함 머신러닝포함 딥러닝
구분주요 아이디어예시
머신러닝데이터에서 규칙과 관계를 학습스팸 분류, 수요 예측
딥러닝여러 층의 신경망으로 복잡한 패턴을 학습이미지 인식, 음성 처리

모델의 결과는 학습 데이터의 대표성, 품질, 목표 설정과 평가 방법에 영향을 받습니다. 높은 정확도만으로 모든 상황에서 공정하고 신뢰할 수 있다고 보장되지는 않습니다.

10.3 / GENERATIVE AI & LLM

생성형 AI와 LLM

생성형 AI는 학습한 데이터의 패턴을 바탕으로 텍스트·이미지·오디오·영상 등 새로운 콘텐츠를 생성하는 모델과 기술입니다. 대규모 언어 모델(LLM, Large Language Model)은 많은 텍스트 데이터를 학습해 문맥에 이어질 토큰을 예측하며 언어 작업을 수행하는 모델입니다.

활용 예

초안 작성, 요약, 번역, 질의응답, 아이디어 탐색 등 작업을 보조합니다.

한계

그럴듯하지만 사실과 다른 결과를 만들 수 있고, 최신성이나 특정 맥락이 부족할 수 있습니다.

책임 있는 사용

중요한 사실은 신뢰할 수 있는 출처에서 검증하고, 민감한 개인정보나 기밀 정보를 입력하지 않도록 주의합니다.

생성 결과는 참고 자료나 초안으로 다루고, 제출·게시·의사결정 전에 사람이 정확성, 출처, 저작권과 편향 가능성을 검토해야 합니다.

10.4 / BIG DATA & ANALYTICS

빅데이터와 데이터 분석

빅데이터는 규모, 생성 속도, 형태의 다양성 등으로 인해 기존 방식만으로 저장·처리·분석하기 어려운 데이터와 관련 기술·접근을 가리킵니다. 데이터 분석은 데이터를 모으고 정리해 질문에 답하거나 의사결정을 지원하는 과정입니다.

문제와 질문 정의→ 데이터 수집·정리→ 분석·검증→ 결과 해석·활용

분석 결과가 유용하려면 데이터의 출처와 수집 방법, 누락·편향 여부, 개인정보 보호를 함께 살펴야 합니다. 상관관계가 발견되었다고 해서 한쪽이 다른 쪽의 원인이라고 단정할 수는 없습니다.

10.5 / CLOUD COMPUTING

클라우드 컴퓨팅

클라우드 컴퓨팅은 네트워크를 통해 서버, 저장 공간, 데이터베이스, 소프트웨어와 같은 컴퓨팅 자원을 필요에 따라 이용하는 방식입니다. 사용량에 맞춰 자원을 조정할 수 있지만, 보안·비용·가용성은 제공자와 이용자가 함께 관리해야 합니다.

IaaS

가상 서버, 네트워크, 저장 공간 같은 기반 자원을 제공합니다.

PaaS

응용 프로그램을 개발·배포할 수 있는 플랫폼과 실행 환경을 제공합니다.

SaaS

브라우저나 앱을 통해 바로 사용할 수 있는 소프트웨어 서비스를 제공합니다.

10.6 / INTERNET OF THINGS

IoT와 사물인터넷

사물인터넷(Internet of Things, IoT)은 센서와 소프트웨어, 네트워크 연결을 갖춘 기기들이 데이터를 수집·교환하고 원격 모니터링이나 자동화에 활용되는 환경과 기술을 말합니다.

센서와 기기→ 네트워크→ 데이터 분석·서비스→ 사용자 또는 제어 장치

스마트 홈, 환경 모니터링, 물류 추적 등에서 활용할 수 있습니다. 연결된 기기의 보안 업데이트, 강한 인증, 필요한 데이터만 수집하는 원칙도 중요합니다.

10.7 / XR & METAVERSE

XR과 메타버스

XR(Extended Reality, 확장현실)은 현실과 디지털 환경을 결합하거나 대체하는 기술을 포괄하는 용어입니다. 메타버스는 사람들이 아바타와 디지털 공간을 통해 상호작용하는 지속적·공유형 가상 환경을 설명할 때 사용되며, 하나의 기술이나 표준으로만 정의되지는 않습니다.

기술설명활용 예
VR가상 환경에 몰입하도록 보여 주는 기술가상 훈련, 시뮬레이션
AR현실 화면 위에 디지털 정보를 겹쳐 보여 주는 기술길 안내, 제품 정보 표시
MR현실과 가상 요소가 공간에서 함께 상호작용하도록 하는 기술설계 검토, 협업

XR 서비스에서는 이용자의 시선·움직임·공간 정보 같은 민감한 데이터가 수집될 수 있으므로, 수집 항목과 저장·이용 방식을 확인해야 합니다.

10.8 / SUMMARY

핵심 정리

  1. 인공지능은 데이터와 알고리즘을 이용해 인식·예측·생성 등의 작업을 수행하도록 하는 기술과 연구 분야입니다.
  2. 머신러닝은 데이터에서 패턴을 학습하고, 딥러닝은 여러 층의 신경망을 활용하는 방법입니다.
  3. 생성형 AI와 LLM은 유용한 결과를 만들 수 있지만, 사실성·편향·개인정보 문제를 검토해야 합니다.
  4. 빅데이터 분석은 질문 정의부터 데이터 정리, 분석, 검증과 해석까지 이어지는 과정입니다.
  5. 클라우드, IoT, XR은 서로 다른 기반 기술과 서비스를 제공하며 보안과 책임 있는 활용이 중요합니다.
