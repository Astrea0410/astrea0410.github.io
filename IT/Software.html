Introduction to Information Technology · Chapter 03

컴퓨터 소프트웨어

소프트웨어의 종류와 운영체제의 역할을 알아보고, 프로그래밍 언어와 프로그램 실행 방식을 살펴봅니다.

IT개론 목차 핵심 정리와 생각해 보기
3.1 / SOFTWARE TYPES

시스템 소프트웨어와 응용 소프트웨어

소프트웨어는 컴퓨터에 작업을 지시하는 프로그램과 관련 데이터를 말합니다. 하는 일에 따라 하드웨어와 프로그램 실행 환경을 관리하는 시스템 소프트웨어, 사용자가 원하는 작업을 수행하는 응용 소프트웨어로 나눌 수 있습니다.

시스템 소프트웨어

컴퓨터 자원을 관리하고 응용 프로그램이 동작할 수 있도록 기본 환경을 제공합니다.

예: 운영체제, 장치 드라이버, 시스템 유틸리티

응용 소프트웨어

문서 작성, 통신, 학습, 콘텐츠 제작 등 사용자의 구체적인 목적을 돕습니다.

예: 웹 브라우저, 문서 편집기, 그래픽 프로그램

사용자→ 응용 소프트웨어→ 운영체제→ 하드웨어

실제로는 응용 프로그램이 운영체제가 제공하는 기능을 이용하고, 운영체제가 장치 드라이버 등을 통해 하드웨어와 상호작용합니다.

3.2 / OPERATING SYSTEM

운영체제(OS)의 역할

운영체제(Operating System, OS)는 컴퓨터의 하드웨어 자원을 관리하고 사용자와 응용 프로그램이 컴퓨터를 사용할 수 있도록 중개하는 시스템 소프트웨어입니다.

프로세스 관리

실행 중인 프로그램에 CPU 시간을 배분하고 프로그램의 실행 상태를 관리합니다.

메모리 관리

프로그램에 메모리를 할당하고, 여러 프로그램이 메모리를 안전하게 사용하도록 조정합니다.

파일 시스템 관리

파일과 폴더를 저장하고 찾을 수 있도록 이름, 위치, 접근 권한 등을 관리합니다.

장치와 사용자 인터페이스

입출력 장치를 제어하고, 그래픽 또는 명령어 기반으로 사용자와 컴퓨터가 소통하도록 합니다.

Windows, macOS, Linux, Android, iOS 등은 다양한 기기에서 사용되는 운영체제의 예입니다. 기기와 목적에 따라 제공 기능과 인터페이스는 다르지만, 자원을 관리하고 프로그램 실행을 지원한다는 공통 역할이 있습니다.

3.3 / PROGRAMMING LANGUAGES

프로그래밍 언어의 종류

프로그래밍 언어는 사람이 컴퓨터가 수행할 작업을 표현하는 규칙과 기호의 체계입니다. 언어는 여러 관점으로 분류할 수 있으며, 아래 분류는 서로 배타적이라기보다 서로 다른 특징을 설명합니다.

분류 관점 종류 설명과 예
추상화 수준 저급 언어 기계가 이해하는 명령에 가까우며 하드웨어를 세밀하게 다룰 수 있습니다. 예: 기계어, 어셈블리어
추상화 수준 고급 언어 사람이 읽고 쓰기 편하도록 표현하며 다양한 분야의 프로그램을 만들 수 있습니다. 예: Python, Java, C
주요 사용 분야 웹 언어와 도구 웹 페이지와 서비스를 만드는 데 활용합니다. 예: JavaScript, HTML, CSS
실행 방식 컴파일·인터프리트 방식 소스 코드를 번역하고 실행하는 도구와 과정이 언어·환경에 따라 다르게 구성됩니다.

언어를 선택할 때는 문제의 성격, 실행 환경, 성능 요구, 이용 가능한 도구와 라이브러리, 팀의 경험 등을 함께 고려합니다.

3.4 / TRANSLATION & EXECUTION

컴파일러와 인터프리터

컴퓨터의 CPU는 궁극적으로 기계가 실행할 수 있는 명령을 처리합니다. 컴파일러와 인터프리터는 프로그래밍 언어로 작성한 코드를 실행 가능한 형태로 처리하는 대표적인 방식 또는 도구입니다.

컴파일러 (Compiler)

소스 코드 전체나 일정 단위를 다른 형태의 코드로 번역한 뒤, 그 결과를 실행하는 방식에 사용됩니다.

일반적인 과정: 소스 코드 → 번역 → 실행

인터프리터 (Interpreter)

실행 환경에서 프로그램의 명령을 해석하고 동작을 수행하는 방식에 사용됩니다.

일반적인 과정: 소스 코드 → 해석·실행

비교 항목 컴파일 중심 실행 인터프리트 중심 실행
처리 시점 실행 전에 번역 단계를 거치는 경우가 많음 실행 환경이 프로그램을 읽고 처리하는 과정에서 해석하는 경우가 많음
오류 확인 번역 단계에서 문법이나 형식 오류를 확인할 수 있음 실행 중 해당 코드에 도달했을 때 오류가 드러날 수 있음
구현의 다양성 실제 언어와 실행 환경은 두 방식을 결합하거나 중간 코드·가상 머신을 이용하기도 하므로, 언어를 한 방식으로만 단정하기 어렵습니다.

예를 들어 Python은 일반적으로 소스 코드를 바이트코드로 변환한 뒤 Python 가상 머신이 실행하는 과정을 사용합니다. 따라서 언어의 실행 방식을 단순히 “컴파일러만” 또는 “인터프리터만” 사용한다고 나누기보다 구현 환경을 함께 살펴보는 것이 정확합니다.

3.5 / SUMMARY

핵심 정리

  1. 시스템 소프트웨어는 컴퓨터 자원을 관리하고, 응용 소프트웨어는 사용자의 구체적인 작업을 지원합니다.
  2. 운영체제는 프로세스, 메모리, 파일, 장치와 사용자 인터페이스 등을 관리합니다.
  3. 프로그래밍 언어는 추상화 수준, 사용 분야, 실행 환경 등 다양한 관점에서 분류할 수 있습니다.
  4. 컴파일러와 인터프리터는 코드를 처리하는 대표적인 방식이며 실제 실행 환경은 두 방식을 함께 활용할 수도 있습니다.
