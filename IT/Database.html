Introduction to Information Technology · Chapter 07

데이터베이스

데이터를 체계적으로 저장하고 활용하는 데이터베이스의 구조와 SQL의 기초를 살펴봅니다.

IT개론 목차 핵심 정리와 생각해 보기
7.1 / DATABASE CONCEPTS

데이터베이스의 개념

데이터베이스(Database)는 여러 사용 목적에 맞게 데이터를 체계적으로 저장하고, 필요할 때 검색·수정·관리할 수 있도록 구성한 데이터의 모음입니다. 예를 들어 학교에서는 학생, 과목, 수강 내역을 연결해 관리할 수 있습니다.

체계적인 저장

데이터를 정해진 구조와 규칙에 따라 저장해 쉽게 찾고 갱신할 수 있습니다.

공유와 활용

권한이 있는 여러 사용자와 응용 프로그램이 필요한 데이터를 활용할 수 있습니다.

정확성과 보호

규칙과 권한을 적용해 데이터의 정확성, 일관성, 보안을 관리합니다.

7.2 / DBMS

DBMS의 역할

DBMS(Database Management System)는 사용자나 응용 프로그램이 데이터베이스를 만들고 이용할 수 있게 해 주는 데이터베이스 관리 시스템입니다. 저장 공간을 관리하는 것뿐 아니라 여러 사용자의 요청과 데이터 보호도 담당합니다.

데이터 정의와 조회

테이블과 구조를 정의하고, 필요한 자료를 조건에 따라 찾거나 요약하도록 지원합니다.

동시성 제어

여러 사용자가 동시에 데이터를 읽고 변경할 때 작업이 서로 충돌하지 않도록 조정합니다.

무결성과 보안

자료가 정해진 규칙을 지키도록 하고, 사용자별 접근 권한을 설정합니다.

복구와 백업

오류나 장애에 대비해 데이터 복구와 백업 기능을 제공합니다.

데이터베이스는 관리 대상인 데이터와 구조를 뜻하고, DBMS는 그 데이터를 관리하고 이용하도록 돕는 소프트웨어입니다.

7.3 / RELATIONAL DATABASE

관계형 데이터베이스

관계형 데이터베이스는 데이터를 행(row)과 열(column)로 구성된 테이블에 저장하고, 테이블 사이의 관계를 키로 표현합니다. 각 테이블은 보통 한 종류의 대상을 기록하도록 설계합니다.

student_id name major
1001민지컴퓨터과학
1002준호정보보호

행과 열

행은 하나의 레코드, 열은 데이터의 속성이나 항목을 나타냅니다.

기본 키 (Primary Key)

테이블의 각 행을 구별하는 값입니다. 중복되거나 비어 있지 않도록 정합니다.

외래 키 (Foreign Key)

다른 테이블의 기본 키를 참조해 테이블 사이의 연결을 표현합니다.

예를 들어 학생 테이블과 수강 테이블을 나누면 학생 정보를 여러 수강 기록에 반복 저장하지 않아도 됩니다. 관계를 키로 연결하면 중복을 줄이고 자료를 일관되게 관리하는 데 도움이 됩니다.

7.4 / SQL BASICS

SQL 기초

SQL(Structured Query Language)은 관계형 데이터베이스의 구조와 데이터를 정의하고 다루는 데 사용하는 언어입니다. 다음 예시는 MySQL을 포함한 여러 DBMS에서 널리 쓰이는 기본 문법입니다.

테이블 만들기

CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    major VARCHAR(80)
);

데이터 추가와 조회

INSERT INTO students (student_id, name, major)
VALUES (1001, '민지', '컴퓨터과학');

SELECT student_id, name, major
FROM students
WHERE student_id = 1001;

데이터 수정과 삭제

UPDATE students
SET major = '정보기술'
WHERE student_id = 1001;

DELETE FROM students
WHERE student_id = 1001;

UPDATE와 DELETE에서 조건을 생략하면 의도하지 않게 많은 행을 변경하거나 삭제할 수 있습니다. 실행 전 대상 데이터를 확인하고, 중요한 작업은 백업과 권한을 점검해야 합니다.

명령 분류 기능
CREATEDDL데이터베이스 객체의 구조를 생성
SELECTDQL조건에 맞는 데이터 조회
INSERTDML새 데이터 추가
UPDATEDML기존 데이터 수정
DELETEDML데이터 행 삭제
7.5 / MYSQL & DATA MANAGEMENT

MySQL과 데이터 관리

MySQL은 널리 사용되는 관계형 데이터베이스 관리 시스템입니다. 데이터베이스와 테이블을 만들고 SQL로 자료를 관리하며, 애플리케이션은 데이터베이스 서버에 연결해 필요한 작업을 요청합니다.

응용 프로그램→ SQL 요청 MySQL DBMS→ 조회·변경 테이블 데이터
  1. 데이터베이스에 저장할 대상과 필요한 항목을 정합니다.
  2. 테이블과 열의 자료형, 기본 키와 외래 키를 설계합니다.
  3. 필요한 데이터를 입력하고, SQL로 조회·추가·수정합니다.
  4. 사용자와 프로그램에 필요한 최소한의 권한만 부여합니다.
  5. 정기적으로 백업하고 복구할 수 있는지 확인합니다.

실제 애플리케이션에서는 사용자 입력을 SQL 문자열에 그대로 이어 붙이지 않습니다. 준비된 문장(prepared statement)과 매개변수 바인딩을 사용하면 입력값을 안전하게 처리하고 SQL 인젝션 위험을 줄이는 데 도움이 됩니다.

데이터 품질과 개인정보

정확하고 최신의 데이터를 유지하고, 중복과 오류를 점검합니다. 개인정보는 목적에 필요한 범위로 수집하고, 접근 권한·보관 기간·삭제 절차를 함께 관리해야 합니다.

7.6 / SUMMARY

핵심 정리

  1. 데이터베이스는 데이터를 체계적으로 저장하고 검색·수정·관리할 수 있도록 구성한 모음입니다.
  2. DBMS는 데이터베이스의 구조와 접근, 무결성, 동시 사용, 보안과 복구를 관리하는 소프트웨어입니다.
  3. 관계형 데이터베이스는 테이블을 기본 키와 외래 키로 연결해 데이터를 관리합니다.
  4. SQL은 데이터베이스의 구조를 정의하고 데이터를 조회·추가·수정·삭제하는 언어입니다.
  5. MySQL로 데이터를 관리할 때 권한, 백업, 데이터 품질, 개인정보 보호와 안전한 SQL 처리를 고려해야 합니다.
