Introduction to Information Technology · Chapter 04

데이터와 정보의 표현

컴퓨터가 숫자와 문자를 비롯한 다양한 데이터를 디지털 형태로 표현하고 처리하는 방법을 알아봅니다.

IT개론 목차 핵심 정리와 생각해 보기
4.1 / BITS & BYTES

비트(Bit)와 바이트(Byte)

컴퓨터는 내부의 데이터를 전기 신호의 두 가지 상태로 구분해 표현하며, 이를 흔히 0과 1로 나타냅니다. 이진수 한 자리를 표현하는 정보의 기본 단위를 비트(bit)라고 합니다.

비트 (bit)

정보를 표현하는 가장 작은 기본 단위입니다. 한 비트는 0 또는 1의 두 상태 중 하나를 가집니다.

바이트 (byte)

일반적으로 8비트를 묶은 단위입니다. 저장장치 용량이나 파일 크기를 나타낼 때 자주 사용합니다.

더 큰 단위

KB, MB, GB, TB 등은 바이트의 크기를 나타내는 단위입니다. 저장장치 표기와 운영체제의 표시 방식에 따라 환산 기준이 다를 수 있습니다.

단위 일반적인 십진 표기 설명
1 Byte (B)8 bits바이트 하나는 8비트입니다.
1 Kilobyte (kB)1,000 Bytes십진 단위 기준입니다.
1 Megabyte (MB)1,000 kB사진이나 문서 파일 크기 등에 사용합니다.
1 Gigabyte (GB)1,000 MB저장장치와 메모리 용량 표기에 사용합니다.

컴퓨터 메모리 용량을 설명할 때는 1 KiB = 1,024 Bytes처럼 2의 거듭제곱을 기준으로 하는 이진 단위도 사용합니다. 따라서 kB와 KiB는 서로 다른 단위입니다.

4.2 / NUMBER SYSTEMS

2진수, 10진수, 16진수

진법은 수를 표현할 때 사용하는 숫자와 자릿값의 규칙입니다. 10진수는 0~9, 2진수는 0과 1을 사용합니다. 16진수는 0~9와 A~F를 사용하며, 긴 이진수를 짧게 표시할 때 편리합니다.

진법 기수 사용 기호 예
2진수20, 1101101₂
10진수100~945₁₀
16진수160~9, A~F2D₁₆

2진수를 10진수로 바꾸기

각 자릿수에 오른쪽부터 2⁰, 2¹, 2²처럼 2의 거듭제곱을 곱해 더합니다.

101101₂
= 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰
= 32 + 8 + 4 + 1
= 45₁₀

16진수와 2진수

16진수 한 자리는 2진수 네 자리(4비트)와 대응합니다. 예를 들어 2D₁₆에서 2는 0010₂, D는 1101₂이므로 00101101₂이며 10진수로는 45입니다.

숫자만 보면 진법을 혼동할 수 있으므로 표기할 때 아래 첨자나 0b, 0x 같은 접두 표기를 활용합니다.

4.3 / TEXT & IMAGES

문자와 이미지의 디지털 표현

문자 표현

컴퓨터는 문자에 정해진 숫자 코드를 대응시켜 저장하고 처리합니다. 문자 인코딩은 문자와 숫자 바이트 사이의 대응 규칙을 정합니다. 같은 바이트라도 어떤 인코딩으로 해석하는지에 따라 다른 문자로 보일 수 있습니다.

이미지 표현

일반적인 래스터 이미지는 작은 점인 픽셀의 모음으로 표현합니다. 각 픽셀의 색상 정보를 저장하므로 해상도와 색상 깊이가 커질수록 표현할 수 있는 정보와 파일 크기도 커지는 경향이 있습니다.

해상도

이미지를 구성하는 가로·세로 픽셀 수입니다. 픽셀이 많으면 세밀하게 표현할 수 있지만 저장할 데이터도 늘어납니다.

색상 깊이

픽셀 하나의 색을 표현하는 데 사용하는 비트 수입니다. 비트 수가 커지면 표현할 수 있는 색의 조합이 많아집니다.

벡터 이미지

픽셀을 하나씩 저장하는 대신 선과 도형을 수학적 정보로 표현합니다. 크기를 바꾸어도 선명함을 유지하기 좋아 로고와 도형에 적합합니다.

예를 들어 픽셀마다 빨강·초록·파랑 성분을 각각 8비트로 저장하는 RGB 표현은 픽셀당 총 24비트를 사용합니다. 실제 파일 크기는 압축, 색상 형식, 파일 구조 등에 따라 달라집니다.

4.4 / ENCODING

데이터 인코딩

인코딩(encoding)은 데이터를 저장·전송·처리하기 위해 정해진 규칙에 따라 다른 형태로 표현하는 과정입니다. 디코딩(decoding)은 그 표현을 규칙에 따라 다시 해석하는 과정입니다.

원본 데이터→ 인코딩 규칙 적용→ 저장 또는 전송→ 디코딩

ASCII

영문 알파벳과 숫자, 기본 기호 등을 표현하기 위해 만들어진 문자 코드입니다.

유니코드

세계 여러 문자에 코드 값을 부여하는 표준입니다. UTF-8은 유니코드 문자를 바이트로 표현하는 가변 길이 인코딩입니다.

이미지·소리·영상 형식

각 매체는 데이터의 구조와 압축 방법을 정한 다양한 인코딩과 파일 형식으로 저장될 수 있습니다.

인코딩은 암호화와 목적이 다릅니다. 인코딩은 호환되는 규칙을 아는 누구나 데이터를 원래 형태로 해석할 수 있도록 표현하는 것이며, 비밀을 보호하려면 별도의 암호화가 필요합니다.

4.5 / DIGITAL PROCESSING

디지털 데이터 처리

디지털 데이터는 숫자 형태로 표현되어 컴퓨터가 저장·복제·검색·전송·분석할 수 있습니다. 텍스트 검색, 이미지 보정, 음성 인식처럼 처리 목적에 따라 적절한 표현과 알고리즘을 사용합니다.

저장과 복제

파일과 기록을 저장장치나 네트워크 서비스에 보관하고 필요한 곳에 복사합니다.

전송과 변환

데이터를 정해진 형식으로 인코딩해 전달하고, 받는 쪽에서 호환되는 규칙으로 해석합니다.

분석과 활용

데이터를 정렬·검색·요약하거나 알고리즘으로 분석해 정보와 결과를 얻습니다.

압축과 데이터 품질

압축은 저장 공간을 줄이거나 전송을 빠르게 하기 위해 데이터를 더 작은 형태로 표현합니다. 무손실 압축은 원본을 복원할 수 있고, 손실 압축은 일부 정보를 줄이는 대신 파일을 더 작게 만들 수 있습니다. 손실 압축은 이미지·소리·영상에서 널리 쓰이지만 반복 저장하거나 강하게 압축하면 품질이 낮아질 수 있습니다.

데이터를 처리할 때는 표현 형식뿐 아니라 정확성, 출처, 개인정보 보호와 접근 권한도 함께 고려해야 합니다.

4.6 / SUMMARY

핵심 정리

  1. 비트는 0과 1로 표현하는 정보의 기본 단위이고, 바이트는 일반적으로 8비트입니다.
  2. 2진수·10진수·16진수는 같은 값을 서로 다른 자릿값 규칙으로 표현합니다.
  3. 문자와 이미지는 코드와 픽셀 등의 규칙을 이용해 디지털 데이터로 표현합니다.
  4. 인코딩은 데이터를 정해진 규칙으로 표현하는 과정이며, 디코딩은 이를 해석하는 과정입니다.
  5. 디지털 데이터는 저장·전송·분석할 수 있고, 처리 과정에서는 압축과 데이터 품질도 고려해야 합니다.
