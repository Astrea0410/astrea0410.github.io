운영체제와 컴퓨터 관리

운영체제의 종류와 작동 방식을 알아보고, 프로세스·메모리·파일을 관리하는 방법을 살펴봅니다.

5.1 / WINDOWS · LINUX · macOS

운영체제의 종류

운영체제(Operating System, OS)는 응용 프로그램과 하드웨어 사이에서 컴퓨터 자원을 관리하고, 사용자가 컴퓨터를 사용할 수 있도록 돕는 시스템 소프트웨어입니다. 컴퓨터와 모바일 기기에는 목적과 하드웨어에 맞는 여러 운영체제가 사용됩니다.

Windows

Microsoft가 개발하는 운영체제입니다. 개인용 컴퓨터에서 널리 사용되며 다양한 상용 소프트웨어와 주변 기기를 지원합니다.

Linux

Linux 커널을 중심으로 구성된 운영체제 계열입니다. 여러 배포판이 있으며 서버, 임베디드 장치, 개인용 컴퓨터 등 다양한 환경에서 사용됩니다.

macOS

Apple의 Mac 컴퓨터를 위한 운영체제입니다. Apple 하드웨어와 긴밀히 통합되어 있고 Unix 계열 기술을 기반으로 합니다.

운영체제를 비교할 때는 사용 목적, 지원하는 프로그램과 장치, 보안 업데이트, 관리 방식, 사용자의 익숙함을 함께 고려합니다. 운영체제마다 파일 경로와 명령어, 설정 방법이 다를 수 있습니다.

5.2 / PROCESSES & THREADS

프로세스와 스레드

프로세스(Process)는 실행 중인 프로그램과 그 실행 상태를 운영체제가 관리하는 단위입니다. 프로세스마다 실행에 필요한 자원과 메모리 공간이 배정됩니다.

스레드(Thread)는 프로세스 안에서 실제 명령을 실행하는 흐름입니다. 하나의 프로세스에는 하나 이상의 스레드가 있을 수 있으며, 같은 프로세스의 스레드는 코드와 데이터 등 일부 자원을 공유합니다.

프로세스→ 자원과 주소 공간→ 하나 이상의 스레드
구분 프로세스 스레드
의미 실행 중인 프로그램과 그에 필요한 자원·상태 프로세스 안에서 명령을 실행하는 흐름
자원 관계 각 프로세스는 일반적으로 독립된 주소 공간을 가짐 같은 프로세스의 스레드는 일부 메모리와 자원을 공유
주의점 프로세스 간 통신에는 운영체제가 제공하는 방법이 필요 공유 데이터에 동시에 접근할 때 동기화가 필요할 수 있음

운영체제는 CPU 시간을 여러 작업에 배분해 동시에 실행되는 것처럼 보이게 하거나, 여러 처리 코어를 활용해 실제로 병렬 실행할 수 있도록 관리합니다. 동시성과 병렬성은 서로 관련 있지만 같은 개념은 아닙니다.

5.3 / MEMORY MANAGEMENT

메모리 관리

운영체제는 실행 중인 프로그램에 메모리를 배정하고, 프로그램이 끝나면 사용하던 공간을 회수합니다. 여러 프로그램이 메모리를 효율적이고 안전하게 사용할 수 있도록 각 프로그램의 메모리 접근을 관리합니다.

할당과 회수

프로그램 실행에 필요한 메모리를 제공하고 더 이상 필요하지 않은 공간을 다시 사용할 수 있게 합니다.

가상 메모리

각 프로세스에 독립적인 주소 공간을 제공하고, 실제 메모리 자원을 관리하기 위한 추상화 기법입니다.

페이징과 보조 저장장치

운영체제는 메모리를 페이지 단위로 관리할 수 있습니다. 일부 시스템은 메모리 압박 시 저장장치를 활용하지만 RAM보다 느리므로 RAM을 완전히 대체하지는 않습니다.

메모리가 부족하면 프로그램이 느려지거나 실행에 실패할 수 있습니다. 사용하지 않는 앱을 닫고, 작업에 맞는 메모리 용량을 확보하면 도움이 됩니다.

5.4 / FILES & DIRECTORIES

파일 및 디렉터리 관리

파일 시스템은 저장장치에 파일과 디렉터리를 구성하고 이름, 위치, 크기, 권한 등의 정보를 관리합니다. 디렉터리(폴더)는 관련 파일과 하위 디렉터리를 계층적으로 정리하는 공간입니다.

경로

파일이나 디렉터리의 위치를 나타냅니다. 절대 경로는 기준 위치에서 전체 주소를, 상대 경로는 현재 위치를 기준으로 표시합니다.

파일 권한

사용자나 그룹이 파일을 읽고, 수정하고, 실행할 수 있는 범위를 제어합니다. 권한 설정은 정보 보호에 중요합니다.

파일 관리 습관

의미 있는 이름과 폴더 구조를 사용하고, 중요한 파일은 별도 위치에 백업합니다. 확장자만 바꿔서는 파일 형식이 변환되지 않습니다.

운영체제에 따라 경로 표기 방식이나 권한 설정 방법이 다를 수 있지만, 파일을 찾고 체계적으로 관리한다는 목적은 같습니다.

5.5 / HOW AN OS WORKS

운영체제의 작동 원리

컴퓨터를 켜면 펌웨어가 기본 하드웨어를 확인하고 운영체제를 시작하는 과정을 진행합니다. 운영체제의 핵심 부분인 커널이 메모리에 올라가 하드웨어와 시스템 자원을 관리하고, 필요한 시스템 서비스와 사용자 환경이 준비됩니다.

전원 켜기→ 펌웨어 초기화→ 부트로더→ 커널 시작→ 서비스·사용자 환경

시스템 호출

응용 프로그램은 시스템 호출을 통해 파일 열기, 메모리 사용, 장치 접근 등 운영체제의 기능을 요청합니다.

인터럽트와 이벤트

하드웨어나 프로그램에서 발생한 이벤트를 운영체제가 처리하고 필요한 작업으로 제어를 넘깁니다.

자원 배분

커널은 프로세스, 메모리, 저장장치와 입출력 장치를 조정해 여러 프로그램이 시스템을 사용할 수 있게 합니다.

운영체제는 실행 중인 작업을 계속 관리합니다. 프로그램이 장치나 파일을 요청하면 운영체제가 권한과 요청을 확인하고 적절한 시스템 기능을 제공합니다.

5.6 / SUMMARY

핵심 정리

  1. Windows, Linux, macOS는 다양한 컴퓨터 환경에서 사용되는 운영체제이며 지원 환경과 관리 방식이 다릅니다.
  2. 프로세스는 실행 중인 프로그램과 자원·상태이고, 스레드는 프로세스 안에서 실행되는 흐름입니다.
  3. 운영체제는 메모리를 할당·회수하고 가상 메모리 등으로 프로그램의 메모리 사용을 관리합니다.
  4. 파일 시스템은 파일과 디렉터리의 위치, 이름, 권한 등 정보를 관리합니다.
  5. 운영체제는 부팅 후 커널과 시스템 서비스를 실행하고, 시스템 호출을 통해 프로그램의 자원 사용을 중개합니다.

  2. 같은 프로세스 안의 스레드가 메모리를 공유하면 어떤 장점과 주의점이 있을까요?
