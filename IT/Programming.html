프로그래밍과 알고리즘

문제를 절차적으로 해결하는 알고리즘부터 기본 프로그래밍 구성 요소와 객체지향 개념까지 알아봅니다.

IT개론 목차 핵심 정리와 생각해 보기
9.1 / PROGRAMMING

프로그래밍의 개념

프로그래밍은 해결할 문제를 분석하고, 컴퓨터가 수행할 명령을 프로그래밍 언어로 표현해 실행 가능한 프로그램으로 만드는 과정입니다. 프로그램을 만들 때는 요구사항을 파악하고, 해결 절차를 설계한 뒤, 코드를 작성·실행·검증하고 개선합니다.

문제 이해→ 해결 절차 설계→ 코드 작성→ 실행·검증·개선
9.2 / ALGORITHMS & FLOWCHARTS

알고리즘과 순서도

알고리즘은 문제를 해결하기 위한 명확하고 순서가 있는 절차입니다. 순서도는 시작·처리·입력과 출력·조건 분기 등을 도형과 화살표로 나타내 알고리즘의 흐름을 시각적으로 표현합니다.

순서도 기호주요 의미예
타원형시작 또는 끝알고리즘 시작
평행사변형입력 또는 출력숫자 입력, 합계 출력
직사각형처리 또는 계산두 수의 합 계산
마름모조건 판단과 분기점수가 기준 이상인가?

두 수 중 큰 수 찾기

  1. 두 수 A와 B를 입력받습니다.
  2. A가 B보다 크거나 같은지 비교합니다.
  3. 조건이 참이면 A, 아니면 B를 결과로 출력합니다.
9.3 / VARIABLES & TYPES

변수와 자료형

변수는 프로그램이 실행되는 동안 데이터를 이름으로 참조할 수 있게 합니다. 자료형은 데이터의 종류와 가능한 연산을 구분하는 데 도움을 줍니다.

자료형예시용도
정수count = 3개수, 횟수, 순번
실수temperature = 21.5측정값, 소수점이 있는 계산
문자열name = "민지"이름이나 문장
논리값is_open = True참 또는 거짓을 나타내는 조건
 
price = 1200
quantity = 3
total = price * quantity

print(f"합계: {total}원")

사용하는 프로그래밍 언어에 따라 자료형을 선언하는 방법과 형 변환 규칙은 다를 수 있습니다.

9.4 / CONDITIONS & LOOPS

조건문과 반복문

조건문은 조건의 결과에 따라 실행할 코드를 선택하고, 반복문은 같은 종류의 처리를 여러 번 수행합니다. 이 두 구조는 알고리즘의 실행 흐름을 만드는 기본 제어 구조입니다.

score = 85

if score >= 60:
    print("통과")
else:
    print("다시 도전해 보세요")

for number in range(1, 4):
    print(number)

조건문

비교·논리 연산 결과에 따라 서로 다른 경로를 실행합니다. 조건이 겹치는 경우 순서와 범위를 확인합니다.

반복문

정해진 횟수나 조건이 만족하는 동안 작업을 반복합니다. 종료 조건을 확인해 원하지 않는 무한 반복을 막습니다.

9.5 / FUNCTIONS & OOP

함수와 객체지향 프로그래밍

함수는 특정 작업을 수행하는 코드를 이름으로 묶어 재사용하도록 합니다. 매개변수로 값을 전달하고 반환값으로 결과를 돌려줄 수 있습니다.

def add(a, b):
    return a + b

print(add(2, 3))

객체지향 프로그래밍(Object-Oriented Programming)은 관련 데이터(속성)와 동작(메소드)을 객체 단위로 묶어 표현하는 방식입니다. 클래스는 객체를 만들기 위한 설계도 역할을 합니다.

class Counter:
    def __init__(self):
        self.value = 0

    def increase(self):
        self.value += 1

counter = Counter()
counter.increase()
print(counter.value)
9.6 / SUMMARY

핵심 정리

  1. 프로그래밍은 문제를 분석하고 해결 절차를 코드로 표현해 실행·검증하는 과정입니다.
  2. 알고리즘은 문제 해결 절차이고, 순서도는 이를 기호와 화살표로 나타낸 표현입니다.
  3. 변수는 데이터를 이름으로 다루게 하고, 자료형은 데이터의 종류와 연산을 구분합니다.
  4. 조건문은 실행 경로를 선택하고 반복문은 작업을 여러 차례 수행합니다.
  5. 함수는 동작을 재사용하게 하고, 객체지향은 관련 데이터와 동작을 객체로 구성합니다.
