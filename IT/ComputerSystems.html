Introduction to Information Technology · Chapter 02

컴퓨터 시스템의 이해

컴퓨터를 이루는 구성 요소와 데이터가 처리되는 원리를 알아보고, 주요 장치의 역할을 살펴봅니다.

IT개론 목차 핵심 정리와 생각해 보기
2.1 / COMPUTER ARCHITECTURE

컴퓨터의 구조와 동작 원리

컴퓨터는 입력된 데이터를 프로그램의 명령에 따라 처리하고, 그 결과를 출력하거나 저장하는 전자 장치입니다. 중앙처리장치(CPU), 주기억장치, 입력·출력 장치가 서로 데이터를 주고받으며 동작합니다.

입력→ 처리→ 출력→ 저장

입력 장치

사용자의 명령이나 외부 데이터를 컴퓨터가 처리할 수 있도록 전달합니다.

중앙처리장치

메모리에서 명령과 데이터를 가져와 해석하고 연산·제어를 수행합니다.

기억 장치

현재 작업에 필요한 정보와 프로그램을 저장하고 처리 결과를 보관합니다.

출력 장치

처리 결과를 화면, 소리, 인쇄물 등의 형태로 사용자에게 전달합니다.

예를 들어 계산기에서 2 + 3을 입력하면 입력 장치가 값을 전달하고, CPU가 연산한 뒤 결과 5를 화면에 출력합니다. 필요하면 이 결과를 저장 장치에 보관할 수도 있습니다.

2.2 / HARDWARE & SOFTWARE

하드웨어와 소프트웨어

컴퓨터 시스템은 물리적으로 만질 수 있는 하드웨어와 하드웨어에 작업을 지시하는 소프트웨어가 함께 동작해야 사용할 수 있습니다.

구분 설명 예시
하드웨어 컴퓨터를 구성하는 물리적인 장치 CPU, 메모리, 키보드, 모니터, SSD
시스템 소프트웨어 하드웨어를 관리하고 응용 프로그램 실행을 돕는 소프트웨어 운영체제, 장치 드라이버, 시스템 도구
응용 소프트웨어 사용자가 특정 작업을 수행하도록 만든 프로그램 웹 브라우저, 문서 편집기, 게임

운영체제가 하드웨어 자원을 관리하고, 응용 프로그램은 운영체제를 통해 장치를 이용합니다. 하드웨어 성능이 좋아도 이를 활용할 소프트웨어가 없으면 원하는 작업을 수행하기 어렵습니다.

2.3 / CPU

CPU: 명령을 실행하는 중앙처리장치

CPU(Central Processing Unit)는 프로그램의 명령을 처리하는 핵심 부품입니다. 명령을 가져오고(Fetch), 해석하고(Decode), 실행하는(Execute) 과정을 반복합니다.

제어 장치 (CU)

명령을 해석하고 컴퓨터 각 부분이 순서에 맞게 동작하도록 제어 신호를 보냅니다.

산술논리연산장치 (ALU)

덧셈 같은 산술 연산과 크기 비교 같은 논리 연산을 수행합니다.

레지스터

CPU 내부에서 연산에 필요한 값과 명령, 중간 결과를 빠르게 임시 저장합니다.

CPU의 성능은 동작 속도뿐 아니라 코어 수, 작업 종류, 메모리와의 연결 등 여러 요소의 영향을 받습니다. 따라서 CPU의 숫자 하나만으로 컴퓨터의 전체 성능을 판단하기는 어렵습니다.

2.4 / RAM & ROM

주기억장치: RAM과 ROM

구분 RAM ROM
이름 Random Access Memory Read-Only Memory
주요 역할 실행 중인 프로그램과 작업 데이터를 임시로 저장 컴퓨터 시작 등에 필요한 펌웨어와 기본 정보를 저장
전원 차단 시 일반적으로 저장된 내용이 사라지는 휘발성 메모리 내용이 유지되는 비휘발성 메모리
주요 특징 용량이 클수록 여러 작업을 원활하게 수행하는 데 도움이 됨 일반적인 RAM처럼 작업 중 데이터를 임시 보관하는 용도는 아님

컴퓨터를 켜면 저장 장치의 운영체제와 프로그램이 RAM으로 읽혀 실행됩니다. RAM은 작업 공간에, SSD나 HDD는 파일을 보관하는 장기 저장 공간에 비유할 수 있습니다.

2.5 / INPUT & OUTPUT

입력장치와 출력장치

입력장치는 사람이 전달하는 명령이나 주변 환경의 데이터를 컴퓨터로 보내고, 출력장치는 처리 결과를 사람이 확인할 수 있는 형태로 표현합니다. 하나의 장치가 입출력 기능을 함께 제공하기도 합니다.

입력장치

키보드, 마우스, 터치스크린, 마이크, 카메라, 스캐너, 센서

출력장치

모니터, 스피커, 프린터, 프로젝터, 햅틱 장치

입출력 겸용

터치스크린은 화면을 보여 주는 동시에 터치 입력도 받습니다. 네트워크 장치는 양방향으로 데이터를 주고받습니다.

장치는 연결 방식과 운영체제의 지원에 따라 동작이 달라질 수 있습니다. 운영체제는 장치 드라이버를 이용해 다양한 하드웨어를 제어합니다.

2.6 / STORAGE

저장장치: HDD와 SSD

저장장치는 컴퓨터의 전원이 꺼져도 프로그램과 파일을 보관하는 비휘발성 장치입니다. 대표적인 저장장치인 HDD와 SSD는 데이터를 저장하는 방식과 특성이 다릅니다.

항목 HDD SSD
저장 방식 회전하는 자기 디스크에 데이터를 기록 플래시 메모리 반도체에 데이터를 저장
특성 기계적으로 움직이는 부품이 있으며 대용량 저장에 널리 사용 움직이는 부품이 없어 일반적으로 빠르고 충격·소음에 강함
고려 사항 충격과 소음, 접근 속도 등을 고려해야 함 용량과 가격, 제품의 쓰기 내구성 등을 고려해야 함

저장장치를 고를 때는 용량과 속도뿐 아니라 가격, 사용 목적, 백업 방법도 함께 생각해야 합니다. 중요한 파일은 한 곳에만 보관하지 말고 별도의 저장장치나 신뢰할 수 있는 백업 공간에 복사하는 것이 좋습니다.

2.7 / SUMMARY

핵심 정리

  1. 컴퓨터는 입력된 데이터를 프로그램의 명령에 따라 처리하고 출력하거나 저장합니다.
  2. 하드웨어는 물리적 장치이고, 소프트웨어는 장치에 작업을 지시하는 프로그램입니다.
  3. CPU는 명령을 해석·실행하고, RAM은 작업 중인 데이터를 임시로 보관하며, ROM은 시작에 필요한 정보를 유지합니다.
  4. 입력장치는 데이터와 명령을 전달하고, 출력장치는 처리 결과를 사용자에게 보여 줍니다.
  5. HDD와 SSD는 데이터를 저장하는 방식과 성능 특성이 다르므로 용도에 맞게 선택합니다.
